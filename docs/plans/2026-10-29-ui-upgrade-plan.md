## 1. 目标、决策与兼容边界

目标：用户从菜单即可查看额度与今日用量；从任何入口进入同一 Provider 时状态与动作一致；设置能说明何时生效；提醒可以配置、验证、接收并回到相关界面。

本轮接受的设计决定（用户已授权根据审查落地）：

- 菜单增加「额度 / 用量」切换，默认保留现有「用量」，记住本机上次选择；额度查看不依赖 edge dock。使用本机 UI 偏好，不新增远端配置同步字段。
- 菜单额度页复用 Provider 卡片的数据与子组件，宽度按内容实际需要适配并遵守屏幕高度封顶；不能把 468pt 详情硬塞入 360pt 菜单。可采用紧凑摘要 + 可展开详情，避免新建重复计量链路。
- 用户自定义 Provider 顺序、fleet scope、单 Provider 刷新和旧数据兜底全部保留。按 spec/sync.md §10.0 保留两轴：用量随 scope 切换，额度始终本机优先的全局有效额度；额度采用 fleetCardContext 与 effective quota 管线，不能用 fleetMenuSummary 代替额度；没有远端详情的数据明确标示本机范围，不伪造远端明细。
- 普通设置采用统一草稿 + 保存并应用；外观加入草稿。Sync 保留独立即时保存且明确提示，边缘窗拖拽位置保持独立即时状态，不能被普通表单覆盖。
- 通知集中配置；保留现有四类事件默认、恢复阈值、冷却、队列重试和 Bark 正式发送屏幕策略。系统拒绝后不循环申请权限。
- 本轮不改额度健康算法、token/金额计算、provider/client 绑定、fetcher 或 Fleet wire 协议。

## 2. 业务闭环与状态矩阵

| 用户任务 | 入口 → 操作 → 结果 | 失败/空态与退出 | 验收 |
|---|---|---|---|
| 查看额度 | 菜单 → 额度 → Provider 摘要/详情 | 无启用项引导设置；未配置行可定位对应设置；首次加载有状态；失败保留旧值并标明 | 关闭 dock 后仍可完成；菜单关闭再开保留选择 |
| 查看用量 | 菜单 → 用量 → Client → 展开模型 | 无记录与未配置区分；长名可获得完整名称；金额/缓存率有标签 | 汇总口径不变；折叠不丢数据；小屏可滚动 |
| 更新数据 | 全局刷新/Provider 刷新/本地用量刷新 | 显示范围与进行中状态；错误可见；不触发另一类隐式重扫 | 额度/用量时间可区分；旧值保持 |
| 配置 Provider | 未配置摘要 → 指定设置页 → 保存 → 返回菜单 | 验证/落盘失败保留草稿且提示；禁用/启用立即反映 | 部分 Provider 已配置时仍有局部引导 |
| 普通设置 | 改草稿 → 未保存标记 → 保存并应用 | 取消丢弃草稿；错误不关闭；切页保留草稿；外部更新不能静默覆盖已编辑草稿 | 外观/通知统一草稿；自启沿用现有登录项先更新、落盘失败回滚、回滚失败明确告知的事务；无修改时保存禁用 |
| 独立设置 | Sync 即时保存、Dock 拖拽 | 当前页说明即时生效；Sync 错误保留重试；普通保存不回退位置 | 独立状态变化不清除其他草稿 |
| 设置通知 | 通知页 → 权限/渠道 → Provider 事件规则 → 保存 | Bark 不完整说明回退系统；系统拒绝显示引导；测试用草稿需明确标注 | 用户不用跨多个 pane 拼装通知配置 |
| 验证 Bark | 通知页 → 测试连接（明确主动发送） | 区分未发送、HTTP/网络失败、服务端接受；屏幕策略另行说明 | 按正式策略跳过不能声称连接成功；不泄露 Key |
| 接收提醒 | 原事件检测 → 原渠道发送 → 点击系统通知 → 对应额度页/详情 | Provider 已禁用/不存在时回菜单或设置并解释；不因导航触发重复通知 | 先验证公开 API 可行性；不能可靠打开菜单时用公开 SwiftUI Window 共享详情兜底；冷启动能力必须实测再声明 |
| 边缘窗 | 界面页 → 模式示意 → 使用/拖拽 | 全屏隐藏、跨屏与位置保存沿用；配置页解释如何展开 | 无需改变默认开启策略；完整/紧凑模式均可理解 |

### 阶段 3：设置导航与事务闭环

- Sidebar 增「界面」「通知」；General 保留刷新、自启、关于；界面收纳外观、状态栏、dock、顺序；通知集中系统/Bark 与所有窗口类 Provider 规则。节假日源放独立高级 section，无需再加一页。
- 将外观纳入草稿与 SettingsSaveTransaction；保存失败可见，取消不写配置；Sync 页明确即时保存且保留现有错误重试。
- 建立普通表单的实际 dirty 比较，排除 Sync/拖拽位置/测试结果/显示密码等瞬时 UI 状态；切页保留；外部配置更新遇 dirty 显示冲突提示，明确选择重新载入，或保留当前整张表单（保存时覆盖普通设置字段）。Sync/拖拽位置继续独立保存，禁止把全表单覆盖描述成字段级合并。
- 集中通知权限状态查询（进入页面/返回活跃时刷新）、主动申请（仅未决定时）、拒绝后的系统设置引导与系统测试入口；不声称获得授权等于一定展示横幅。
- Bark 测试明确使用当前草稿；提供主动测试连接与当前正式发送策略状态，主动发送操作必须文案明确。失败、取消、接受结果各自可辨，沿用脱敏。

- 责任文件：`Views/Settings*.swift`、`Services/QuotaUpdateNotifier.swift`、必要导航/配置类型与测试、settings/notifications/config/source-map specs。
