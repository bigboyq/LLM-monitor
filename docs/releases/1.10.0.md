# LLM Monitor 1.10.0

[English](#english) · [简体中文](#简体中文)

## English

This release tunes refresh resilience: two-tier HTTP timeouts, fixed-interval retry on failure, a retired legacy config key, and a strictly menu-bar app.

### Highlights

- **Two-tier HTTP timeouts**: domestic quota endpoints (MiniMax, GLM, DeepSeek) now time out after 10 seconds, and overseas endpoints (Codex) after 15 seconds. Domestic endpoints measured p99 ≤ 0.8s and max ~1.8s over 600+ samples, so 10s still survives TCP SYN retransmits while keeping the UI from hanging on network hiccups.
- **Fixed-interval retry on failure**: failed refreshes no longer stretch the retry interval with exponential backoff. A failing provider simply retries once on the next scheduled tick and is skipped for the rest of the current one, so recovery starts as soon as the upstream service recovers. The 1-second deferred re-wake for cancelled requests is unchanged.
- **Retired `statusBarIndicatorMode`**: the config key has had no effect since 1.9.0 and is now removed from the code. Leftover values in config.json are safely ignored and disappear on the next config save.
- **Pure menu-bar app**: opening the Settings window no longer makes the app icon appear in the Dock; the accessory activation policy is now fixed for the whole lifetime.

### Install

Download `LLM-monitor-1.10.0.dmg` from the release assets, drag **LLM-monitor.app** into **Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is ad-hoc signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

本版本聚焦刷新链路的健壮性调优：HTTP 超时国内外分档、失败改为固定间隔重试、退役无用配置键，并保持纯菜单栏形态。

### 主要更新

- **HTTP 超时国内外两档**：国内额度端点（MiniMax、GLM、DeepSeek）超时收紧为 10 秒，海外端点（Codex）15 秒。国内端点实测 600+ 样本 p99 ≤ 0.8s、最慢 ~1.8s，10 秒仍可扛住 TCP SYN 重传，同时避免网络抖动让界面长时间卡在刷新状态。
- **失败改为固定间隔重试**：刷新失败不再指数退避拉长重试间隔；失败的 provider 直接随下一个定时周期重试一次，上游服务恢复后第一时间自愈。请求被取消时的 1 秒短重试早醒机制保持不变。
- **退役 `statusBarIndicatorMode` 配置键**：该键自 1.9.0 起已无实际作用，现从代码中移除；config.json 中残留旧值会被安全忽略，下次保存配置时自动消失。
- **纯菜单栏形态**：打开设置窗口等操作不再使应用图标出现在 Dock 中，应用全程固定 accessory 激活策略。

### 安装

从 Release 附件下载 `LLM-monitor-1.10.0.dmg`，将 **LLM-monitor.app** 拖入 **Applications**，并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开如遇 Gatekeeper 拦截，请右键 →「打开」。
