# LLM Monitor 1.10.1

[English](#english) · [简体中文](#简体中文)

## English

A patch release restoring GLM local usage tracking after the Zcode CLI's database migration.

### Highlights

- **Fixes silent GLM usage loss after the Zcode upgrade**: today's Zcode `0020_provider_model_selection` migration started writing coding-plan usage under a new `account:bigmodel-` provider prefix (e.g. `account:bigmodel-individual-coding-plan`). The scanner only recognized the old `builtin:bigmodel-` prefix, so every request made after the upgrade was silently dropped from local stats. Both prefixes are now recognized: account coding plans (`*-coding-plan`) count into the quota window exactly like the legacy plan, while `account:`-prefixed trial plans land in the "other plans" bucket. The scan cache version is bumped so the next launch re-scans and backfills everything missed since the migration.
- Model names were NOT part of the migration and are unchanged (`GLM-5.3` / `GLM-5.3-Flash`), so pricing and per-model grouping continue to work as before.

### Install

Download `LLM-monitor-1.10.1.dmg` from the release assets, drag **LLM-monitor.app** into **Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is ad-hoc signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

补丁版本：修复 Zcode CLI 数据库迁移后 GLM 本地用量静默丢失的问题。

### 主要更新

- **修复 Zcode 升级后 GLM 用量静默漏采**：今日 Zcode 执行的 `0020_provider_model_selection` 迁移把 Coding Plan 用量改写到新的 `account:bigmodel-` provider 前缀（如 `account:bigmodel-individual-coding-plan`）。扫描器此前只识别旧的 `builtin:bigmodel-` 前缀，升级后的每一次请求都没能进入本地统计。现已同时识别两种前缀：账号套餐（`*-coding-plan`）与旧版 Coding Plan 同等计入额度窗口，`account:` 前缀的体验套餐归入「其他任务」。扫描缓存已升版，下次启动会自动重扫并补齐迁移以来漏掉的全部数据。
- model name 不在本次迁移范围内，`GLM-5.3` / `GLM-5.3-Flash` 均无变化，计价与按模型分组不受影响。

### 安装

从 Release 附件下载 `LLM-monitor-1.10.1.dmg`，将 **LLM-monitor.app** 拖入 **Applications**，并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开如遇 Gatekeeper 拦截，请右键 →「打开」。
