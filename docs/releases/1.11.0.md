# LLM Monitor 1.11.0

[English](#english) · [简体中文](#简体中文)

## English

A feature release introducing the Icon Duo status bar style, a classic App icon restoration, and a memory leak fix for long-running sessions.

### Highlights

- **Icon Duo status bar style**: the 1.9.0 quota dashboard layout now lives on as its own icon style — left and right arcs for the 5-hour and weekly quotas, a center sector that opens 0–360° based on the lowest 5-hour remaining ratio across plans, three plan health dots at the bottom, and the energy/sleep status dot on top. The "App icon" style simultaneously returns to its classic 1.6.0–1.8.x look (outer weekly ring, inner 5-hour ring filling counter-clockwise, center water cup tinted by alarm state). Existing App-icon users are migrated back to the classic style automatically; switch to Icon Duo for the new layout.
- **Fixed memory growth across refreshes**: the Antigravity fetcher used to create a fresh delegate-backed URLSession on every construction — one per quota refresh, per local-usage reconcile pass, per auth probe — and none were ever invalidated. Default settings leaked dozens of sessions per hour, so resident memory crept up for as long as the app ran. A single process-wide session is now shared, and a pointless fetcher construction in the reconcile path is gone. Long-running memory no longer trends upward.
- **Sleep-blocker awareness in the main panel**: the header now shows an "N apps are preventing sleep" notice that expands into the offender list (process · PID · assertion type · duration) on hover, and the footer energy light refreshes the instant the panel opens instead of waiting for the next scheduled health check.
- **Icon pipeline polish**: `AppIcon.icns` is regenerated in sync with the updated master art (older macOS fallback routes had been showing a stale icon), settings-page icon previews are cached (dragging the interval slider or color pickers no longer rebuilds SVG images on every tick), and the header's full app icon holds a 128px downsampled bitmap (~64KB) instead of a ~4MB decoded 1024px bitmap.

### Install

Download `LLM-monitor-1.11.0.dmg` from the release assets, drag **LLM-monitor.app** into **Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is ad-hoc signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

功能版本：新增 Icon Duo 状态栏图标方案、恢复经典 App 图标，并修复长时间运行的内存持续增长。

### 主要更新

- **Icon Duo 状态栏图标**：1.9.0 重写的额度仪表盘布局独立为一种图标方案——左右弧线分别显示 5 小时与周额度，中心扇形按所有套餐中最低的 5 小时剩余比例动态展开 0～360°，底部三个套餐健康点与顶部节能/睡眠状态点。同时「App 图标」（quotaLogo）恢复为 1.6.0–1.8.x 的经典样式（外环周额度、内环 5 小时额度、中心水位杯颜色跟随警报状态）；已选择 App 图标的用户升级后自动回到经典样式，需要新布局请切换到 Icon Duo。
- **修复内存随刷新持续增长**：Antigravity 抓取器此前每次构造都新建一个带 delegate 的 URLSession 且从不释放——每轮额度刷新、每次用量 reconcile、每个认证探测各泄漏一份，默认配置每小时累积数十个，应用运行多久内存就涨多久。现改为进程级共享单个 session，并消除 reconcile 路径中无谓的抓取器构造；长时间运行内存不再单调上涨。
- **主面板睡眠阻断感知**：header 新增「N 个应用正在阻止休眠」提示，悬浮展开阻止休眠的应用清单（进程名 · PID · 断言类型 · 已持续时长）；footer 节能健康灯在面板打开瞬间即时刷新，不再等待下一次调度健康检查。
- **图标链路打磨**：`AppIcon.icns` 与更新后的主视觉素材重新同步（旧 macOS 回退路线此前会显示旧图标）；设置页图标预览加入缓存，拖动刷新间隔滑杆或取色器不再逐 tick 重建图像；主面板 header 的完整 App 图标改为持有 128px 降采样位图（约 64KB，替代约 4MB 的 1024px 解码位图），24pt 显示视觉无损。

### 安装

从 Release 附件下载 `LLM-monitor-1.11.0.dmg`，将 **LLM-monitor.app** 拖入 **Applications**，并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开如遇 Gatekeeper 拦截，请右键 →「打开」。
