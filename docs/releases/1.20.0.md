# LLM Monitor 1.20.0

[English](#english) · [简体中文](#简体中文)

## English

A consolidation release centered on a new **edge status dock**: an optional always-on strip on
any screen edge showing every provider's quota as dual rings. On top of that, one time-aware
color rule across every surface, side-by-side 5h/weekly hover details, a wider local usage
ledger (ZCode now feeds the DeepSeek and MiniMax cards), new model pricing, bounded recovery
for local-usage scanning, and two crash-class defects gone.

### Highlights

- **New: edge status dock** (Settings → General → Edge status dock): an optional always-on
  strip docked flush to any screen edge — top/bottom/left/right is decided by dragging it
  there. Each enabled provider renders as a dual ring (outer = 5-hour quota, inner = weekly,
  each taking that provider's tightest plan) around a real brand logo, with a persistent
  remaining-quota number underneath — readable without hovering. Hovering a ring pops out the
  same provider card used in the main menu. Four forms in one dropdown: off / full rings /
  mini rings / auto-hide (**default: auto-hide** — collapses to a thin ring column, expands on
  approach with a synchronized 0.25 s window+content transition). The dock is permanent dark
  liquid glass, mouse-transparent by default, auto-hides while the current Space has a
  fullscreen window (optional), follows the provider order configured in Settings, can be
  dragged across displays, and survives replugging via display UUID.
- **One time-aware color rule everywhere**: the status bar and the provider cards share a
  single `colorLevel` threshold — under 15% is red; a short 5-hour window turns yellow below
  30%; a long window (≥24h) uses `min(time remaining, 50)`. The SF Symbol status dot, the Icon
  Duo center, the Icon Duo bottom dots, and the card header dot all agree. Concrete shifts:
  35% remaining on a 5-hour window is now green (was yellow), 15% is now yellow (was red).
- **The center sector follows the plan in service**: it shows the lowest "actually available"
  ratio across plans (`min(5-hour remaining, weekly remaining × weekly multiplier)`), and a
  plan that is fully used up drops out of that comparison instead of dragging the ring to
  zero. When every plan is exhausted the ring correctly reads zero (red); when no plan is
  configured it stays gray.
- **Side-by-side 5h / weekly hover details**: main-menu model rows now show the two windows as
  aligned columns (was stacked with a divider); a side-by-side predicate that never actually
  fired was removed along with its dead stacking branch.
- **Settings → Clients**: the client switcher is now a native `NSSegmentedControl` (grows and
  scrolls instead of ellipsizing labels), and a row with a single provider starts expanded.
- **Wider local usage ledger**: ZCode's shared database now feeds the DeepSeek and MiniMax
  cards too. Rows whose `provider_id` starts with `minimax` / `deepseek` used to be dropped by
  the GLM-only scan; they are now partitioned into slices and merged into the corresponding
  cards (today / 7-day chart / recent samples), **on by default** — disable via the
  `zcode → minimax` / `zcode → deepseek` entries in `clientBindings` (config.json). DeepSeek
  local charts no longer require OpenCode.
- **New model pricing**: GPT-6.1 Sol (Input $2 / Cached $0.1 / Output $10 per million), plus
  GPT-6 Sol, GPT-5.6 Sol and GPT-6 Luna; MiniMax M3.1 Flash (¥2.1 / ¥0.42 / ¥8.4, matching
  M3's published CNY price) so `MiniMax-M3.1-Flash-Preview` is no longer silently priced as M3.
- **Recovery action for local usage**: Settings → Antigravity gains a "Force full rebuild of
  local cache" button that re-requests trajectory metadata for every session, ignoring the
  cache. All scanner caches now live in one app-owned directory
  (`~/Library/Application Support/LLM-monitor/token-monitor/`); the first run after upgrading
  rebuilds from the clients' own data (your original databases are never touched).
- **Budget-truncated usage now says so**: when a scan hits its per-round file/byte budget, both
  the Settings client row and the 7-day chart hover show an orange note that the oldest
  sessions were left out. The menu-bar "App icon" option now uses the fixed design asset
  instead of being redrawn (it no longer changes with quota/health).
- **Smaller package**: the bundled app icon is downsampled to 256px and release builds use
  `-Osize`. The app shrinks from 5.9MB to 4.7MB (DMG 4.1MB → 3.3MB).
- **Stability fixes**, including two crash-class defects: a corrupted Antigravity step-timestamp
  blob could trap the whole process while parsing (now rejected safely), and a file-watcher
  callback bypassed actor isolation, risking a crash on stop/start cycles. Also fixed: a
  duplicate-id crash in the shared display ordering, the 7-day token chart clipping its first
  and last bars, a batch of edge-dock geometry / hit-testing / drag issues, manual refresh of
  one card no longer reshuffling every other provider's schedule, SQLite immutable-read
  hardening (race narrowing, CORRUPT fallback, fingerprint-validated temp copies), quota
  refresh resilience to missing percentages/reset times, notification cooldowns no longer
  burned while unauthorized, and the HTTP response size limit actually being enforced (it
  previously never ran).

### Upgrade notes

- The local-usage cache version was bumped: ZCode performs one full rescan on first run.
- The edge dock defaults to the auto-hide form, so after upgrading you will see a thin ring
  column at the screen edge. If you don't want it: Settings → General → Edge status dock →
  Form → **Off**.

### Install

Download `LLM-monitor-1.20.0.dmg` from the release assets, drag **LLM-monitor.app** into
**Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is ad-hoc
signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

整合版本：新增**边缘状态窗**——常驻任意屏幕边缘的小窗，把每个 Provider 的额度画成双环。
同时：红黄绿判定全界面统一为一套时间感知规则，主菜单 hover 详情改两列并排，本地用量账本
扩容（ZCode 现在也喂 DeepSeek 与 MiniMax 卡），新增模型定价，本地用量扫描补上有界恢复，
并修掉两处崩溃级缺陷。

### 主要更新

- **新增「边缘状态窗」**（设置 → 常规 → 边缘状态窗）：可选的屏幕边缘常驻小窗，贴哪条边由
  拖动决定。每个已启用的 Provider 显示为一个双环圆——外环 5 小时额度、内环周额度（各取该
  Provider 内最吃紧的套餐），中心为真实品牌图标，圆下常驻额度数值，不悬停也能直接读。悬停
  圆环弹出与主菜单同一张 Provider 卡片。形态四选一：无 / 完整圆环 / 小圆环 / 自动隐藏
  （**默认自动隐藏**——平时收起为小圆环列，靠近时窗口与内容同步 0.25 秒展开）。背板为常驻
  暗色液态玻璃，鼠标默认穿透，当前 Space 有全屏窗口时自动隐藏（可关），顺序跟随设置页配置，
  可拖拽跨屏（按显示器 UUID 记忆，拔掉自动回落主屏）。
- **红黄绿判定全界面统一**：状态栏与 Provider 卡片共用同一套 `colorLevel` 阈值——低于 15%
  判红；5 小时短窗口低于 30% 判黄；24h 以上长窗口用 `min(剩余时间%, 50)`，越接近重置黄线越
  紧。SF Symbol 状态圆点、Icon Duo 中心扇形、Icon Duo 底部三点、卡片头部点口径一致。行为
  变化示例：5 小时剩余 35% 由黄转绿，15% 由红转黄。
- **中心扇形跟随在服役的套餐**：显示各套餐「实际可用」（`min(5 小时剩余, 周剩余 × 周倍率)`）
  的最低值，已完全用完的套餐不再参与比较、不再把环拖到 0；全部耗尽时如实显示 0（红），无
  套餐时保持灰色。
- **主菜单 hover 详情 5h / 周两列并排**（此前上下堆叠隔分隔线）；顺带删掉一个从未生效的
  并排/堆叠切换谓词及其死分支。
- **设置页「客户端」**：客户端切换条改用系统 `NSSegmentedControl`（客户端变多时整体变宽并
  横向滚动，不再压成省略号）；只有一个 Provider 的行默认展开。
- **本地用量账本扩容**：ZCode 的共享账本现在也喂 DeepSeek 卡与 MiniMax 卡。此前 `provider_id`
  以 `minimax` / `deepseek` 开头的行在 GLM 单源扫描时被直接丢弃，现按前缀切成独立分片并入
  对应卡片（today / 7 天柱图 / 最近样本），**默认开启**——不需要时把 config.json
  `clientBindings` 里 `zcode → minimax` / `zcode → deepseek` 改为 `false`。DeepSeek 的本地
  token 图表不再依赖 OpenCode。
- **新增模型定价**：GPT-6.1 Sol（Input $2 / Cached $0.1 / Output $10 每百万），以及 GPT-6 Sol、
  GPT-5.6 Sol、GPT-6 Luna；MiniMax M3.1 Flash（¥2.1 / ¥0.42 / ¥8.4，沿用 M3 已公布的人民币
  价目），`MiniMax-M3.1-Flash-Preview` 不再被关键字误兜成 M3 价格。
- **本地用量的恢复入口**：设置页 Antigravity 区新增「强制全量重建本地缓存」按钮，忽略缓存对
  所有 session 强制重新请求 trajectory metadata。五个 scanner 的缓存集中到统一目录
  （`~/Library/Application Support/LLM-monitor/token-monitor/`），升级后首次运行从客户端原始
  数据冷重建（客户端自己的数据库不会被改动）。
- **预算截断如实提示**：单轮扫描触及文件数/字节预算时，设置页客户端行与 7 天柱图悬浮明细都
  会给出橙色提示，不再把不完整数字当完整用量。菜单栏「App 图标」改用固定设计稿，不再随额度
  与健康度重绘。
- **安装包更小**：打包图标降采样到 256px，release 构建启用 `-Osize`。App 包 5.9MB → 4.7MB
  （DMG 4.1MB → 3.3MB）。
- **稳定性修复**，含两处崩溃级缺陷：Antigravity 步级时间戳的损坏 blob 此前会在解析时 trap
  整个进程（现安全拒绝）；文件监听回调此前绕过 actor 隔离，stop/start 周期下有崩溃风险。
  此外修复：共用排序在 id 重复时崩溃；7 天 token 图表首尾两根柱被裁；边缘状态窗的一批几何 /
  命中判定 / 拖动问题；手动刷新单卡不再打乱其他 provider 排期；SQLite immutable 直读加固
  （竞态收窄、CORRUPT 回退、副本指纹校验）；额度刷新对缺失百分比 / 重置时间的韧性；未授权
  期间不再白烧通知冷却；HTTP 响应体上限此前从未真正生效，现已实际执行。

### 升级注意

- 本地用量缓存版本升级：ZCode 首次扫描会全量重算一次。
- 边缘状态窗默认「状态窗（自动隐藏）」，升级后屏幕边缘会出现一条小圆环列；不想要的话在
  设置 → 常规 → 边缘状态窗 → 形态选「**无**」。

### 安装

从 Release 附件下载 `LLM-monitor-1.20.0.dmg`，将 **LLM-monitor.app** 拖入 **Applications**，
并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开如遇 Gatekeeper 拦截，
请右键 →「打开」。
