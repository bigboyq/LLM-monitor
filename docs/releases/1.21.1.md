# LLM Monitor 1.21.1

[English](#english) · [简体中文](#简体中文)

## English

A follow-up patch to 1.21.0: two quality-of-life features that had been lost in the menu
redesign are back, plus a round of architecture cleanup with zero behavior change beyond
the items below.

### Fixes & improvements

- **Account info is back on the hover card**: the email / plan / data-source block lost its
  only UI entry when the menu switched to the client view — it now lives at the bottom of the
  quota-window usage detail (below the per-card reset-credit list) on the Antigravity and
  ChatGPT cards.
- **Per-provider refresh returns**: right-click a pill in the menu's Provider status strip to
  refresh just that provider (same entry point as before the redesign — only that provider's
  schedule is re-anchored; the item is disabled while a refresh job is in flight).
- Model rows now show compressed display names (`3.8-flash-n` instead of `gemini-3.8-flash-n`)
  so variant suffixes stay readable in the fixed-width column; hovering shows the full model ID.
- The menu's today summary is now cached and only recomputed when statuses actually change
  (the 1 Hz clock tick no longer re-runs pricing); it also rolls over automatically at midnight.
- Internal: native samples (Antigravity / MiniMax Code / ZCode) get promptID namespaces at the
  projection layer (`antigravity:` / `minimax-code:` / `zcode:`) so IDs can never collide across
  ledgers — disk caches need no migration and no double counting. Dead code removed
  (`StatusIndicator`, `OpencodeProviderUsage.cost`, three always-true layout predicates, the
  dead `menuLayout` branch family), and the largest scanner file was split
  (AntigravityLocalUsageScanner 1694 → 1217 lines). Two status-bar tests no longer depend on
  the real clock (they used to fail whenever a run landed inside GLM peak hours).

### Install

Download `LLM-monitor-1.21.1.dmg` from the release assets, drag **LLM-monitor.app** into
**Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is ad-hoc
signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

1.21.0 的补丁版本：菜单改版后丢掉的两个体验找回，外加一轮零行为变化的架构清理。

### 修复与改进

- **账号信息回到悬浮卡**：菜单切到客户端视角后，邮箱 / 套餐 / 数据来源失去唯一查看入口——现在
  位于额度窗口用量明细末尾（逐张重置卡清单下方），Antigravity 与 ChatGPT 卡可见。
- **单 Provider 刷新回归**：菜单 Provider 状态行的胶囊右键「刷新 <provider 名>」，与改版前同一
  入口（只重锚该 provider 的排期），刷新事务在飞时置灰。
- 模型行展示压缩品牌前缀（`3.8-flash-n` 而非 `gemini-3.8-flash-n`），变体后缀在定宽列里可区分，
  悬停显示完整模型 ID。
- 菜单今日汇总改为缓存计算：仅在状态真正变化时重算（1Hz 时钟 tick 不再逐秒重跑计价），跨零点
  自动失效。
- 内部：原生样本（Antigravity / MiniMax Code / ZCode）在投影层统一加 promptID 前缀
  （`antigravity:` / `minimax-code:` / `zcode:`），杜绝跨账本撞 ID——磁盘缓存零迁移、零双计。
  死代码清理（`StatusIndicator`、`OpencodeProviderUsage.cost`、三条恒真排版谓词、`menuLayout`
  死分支族），最大的 scanner 文件完成切分（AntigravityLocalUsageScanner 1694 → 1217 行）。
  两条状态栏测试不再依赖真实时钟（此前落在 GLM 高峰时段必挂）。

### 安装

从 Release 附件下载 `LLM-monitor-1.21.1.dmg`，将 **LLM-monitor.app** 拖入 **Applications**，
并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开如遇 Gatekeeper 拦截，
请右键 →「打开」。
