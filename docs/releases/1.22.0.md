# LLM Monitor 1.22.0

[English](#english) · [简体中文](#简体中文)

## English

A UI restructure release: the provider hover card is rebuilt as three reading sections
with fully resident tables, the quota-window block becomes a real two-table layout with
zero-value folding and compact money units, and per-provider forced refresh gains two new
entry points. A round of audit-driven dead-code cleanup rides along.

### Added

- **Provider card, three sections** (shared by the edge-dock popover and the menu strip's
  hover card): an **Account Info** row (account name + plan pill — the pill moved here from
  the card header; the row shows whenever either a real account or a real level exists,
  DeepSeek / MiniMax hide it entirely) → **Plan Info** with four resident modules (quota
  bars, 额度分析, 额度详情, reset-credit details) → the unchanged **7-day usage** card.
- **额度分析 (quota analysis) as a table**: header `类型 | 用量 | 命中 | 产出比 | 思考 | 价值`,
  six columns aligned across rows; numeric cells right-aligned with headers following their
  column. The old `📈 today` footer row moved up as the 今 row of this table, same formulas,
  now also showing output-to-input at **three decimals** and reasoning share.
- **额度详情 (quota details) table**: `类型 | Input | Cached | Output | Reason | 重置日期` —
  the four absolute buckets and each window's reset time (with countdown) are always on
  screen, plus a 今 row (reset cell `—`). The reset-date column has a fixed width and shows
  in full; the reset-credit module is the collapsed row followed by the per-card list
  (hidden entirely at zero).
- **Zero-value folding**: rows (5h/周/今) whose four buckets sum to 0 disappear from both
  tables; a column (e.g. 命中 when nothing was ever cached) disappears module-wide with its
  header; a module with no surviving rows — title included — disappears.
- **Compact money units**: values ≥ 100,000 render as `¥123.5K` / `¥1.23M` / `$2.50B`
  (K/M/B ladder, the same language as the 用量 column; partially-priced suffix carried
  over; below threshold the original-currency two-decimal form is verbatim).
- **Two new per-provider forced-refresh entry points**: left-click a pill in the menu's
  Provider status strip (same route as the right-click item — only that provider's schedule
  is re-anchored; repeat clicks are absorbed by the refresh-transaction gate), and an
  「立即刷新」 button in each enabled provider's authentication & refresh section of
  Settings (grey with a spinner while a refresh job is in flight).
- **Critical health colour tokenized**: `criticalTint` (adaptive systemRed) now backs the
  progress bars, state capsules and reset-credit row, replacing scattered `.red` literals.

### Changed

- Menu bar panel: the today summary row ends with a **bare refresh time** (HH:mm, keeping
  the 「计算中…」 state) and the bucket bar owns its whole row; the hit-rate column drops
  its 「命中」 prefix; the Provider status strip loses its text label and now shows up to
  **five** providers (the 6th folds into +N).
- The hover card has **no hover-collapsed sections any more** — quota analysis, the raw
  table, the per-card reset-credit list and account info are resident, so a mid-refresh
  `.loading` flash can no longer drop a section. Output-to-input is fixed at three decimals.
- Internal: audit-driven dead-code removal (`LocalUsagePart` dead branch family, the reset
  card's hover-expansion branch, `ResetCreditsInfo.shouldDisplay`, four unused font tokens),
  the freshness capsule and bare-text variants share one state machine, menu hairlines
  converge into `MenuHairline`, and the card's width budget is pinned to the **420pt**
  content width both hosts actually use.

### Install

Download `LLM-monitor-1.22.0.dmg` from the release assets, drag **LLM-monitor.app** into
**Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is
ad-hoc signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

一次界面重构版本：Provider 悬浮卡改为三段式阅读结构、额度窗口区块落成真正的双表格布局
（含零值折叠与金额紧凑单位），单 Provider 强制刷新新增两个入口；同船一轮审计驱动的死代码清理。

### 新增

- **Provider 卡片三段式**（边缘状态窗弹出与菜单兜底行 hover 共用）：「账号信息」行（账号名 +
  套餐档位 pill，原标题行的 pill 移入；有账号或级别其一即显示，DeepSeek / MiniMax 不显示）→
  「Plan详情」四个常驻模块（额度条、额度分析、额度详情、重置卡详情）→「最近 7 天 Token 用量」不变。
- **额度分析表格化**：表头 `类型 | 用量 | 命中 | 产出比 | 思考 | 价值`，六列跨行对齐；数值
  右对齐、表头跟随列对齐。原卡片底部的「今日使用情况」上移为「今」行，同公式补齐产出比与
  思考（产出比固定三位小数）。
- **额度详情表格**：`类型 | Input | Cached | Output | Reason | 重置日期`——四桶绝对值与
  重置时刻（带倒计时）常驻，末尾接「今」行（重置格 `—`）；重置日期列固定宽完整显示；重置卡
  模块 = 折叠行 + 逐张清单（0 张整块隐藏）。
- **零值自动折叠**：四桶合计为 0 的行（5h / 周 / 今）在两个表格都不出现；某列（如从未有缓存的
  命中列）在所有行合计为 0 时连表头整列隐藏；行全跳光时模块连标题一起消失。
- **价值列紧凑单位**：≥ 10 万自动换 `¥123.5K` / `¥1.23M` / `$2.50B`（K/M/B 阶梯，与用量列
  同一套语言；部分计价后缀跟随；阈值下保持原币种两位小数）。
- **单 Provider 强刷两个新入口**：菜单 Provider 兜底行**左键点按**立即刷新（与右键同一入口，
  只重锚该 provider 排期，重复点击由刷新事务闸门兜底）；设置页每个已启用 provider 的
  「认证与刷新」区新增「立即刷新」按钮（在飞时置灰并显示进行态）。
- **健康色 token 化**：critical 档新增 `criticalTint`（系统红自适应），额度条 / 状态胶囊 /
  重置卡行的散写红色统一收敛。

### 变更

- 状态栏下拉菜单：今日合计行尾直接显示裸刷新时间（HH:mm，保留「计算中…」状态），占比条独占
  整行；命中率去掉「命中」前缀；Provider 状态行去掉文字标签，可见容量 4 → 5 个（第 6 个起
  折叠为 +N）。
- 悬浮窗不再有 hover 折叠段——额度分析 / 额度详情 / 重置卡清单 / 账号信息全部常驻，刷新中途
  不再闪段；产出比固定三位小数。
- 内部：审计驱动的死代码清理（`LocalUsagePart` 死分支族、重置卡 hover 展开分支、
  `ResetCreditsInfo.shouldDisplay`、4 个无引用字体 token），新鲜度胶囊与裸文本合并共享状态机，
  菜单发丝线收敛为 `MenuHairline`，悬浮卡宽度核算统一到两个宿主实际的 **420pt**。

### 安装

从 Release 附件下载 `LLM-monitor-1.22.0.dmg`，将 **LLM-monitor.app** 拖入 **Applications**，
并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开如遇 Gatekeeper 拦截，
请右键 →「打开」。
