# LLM Monitor 1.23.0

[English](#english) · [简体中文](#简体中文)

## English

A new local-ledger client release: **Agy** — the Antigravity CLI sibling
(`~/.gemini/antigravity-cli/`) — now feeds its plaintext session transcripts into the
monitor as an independent client. Its token usage lands on the Google Antigravity card
next to the IDE ledger; the model name is recovered from the CLI's run logs, and
reasoning tokens are split out of output with the shared character-proportion formula.
Quota windows and pricing are untouched.

### Added

- **Agy, a new local usage client** (Antigravity's CLI branch): every session is written
  to `~/.gemini/antigravity-cli/brain/` as plaintext JSONL transcripts. Settings →
  Clients gains an Agy tab automatically; its tokens count toward the Google Antigravity
  card, side by side with the IDE's local ledger. The quota provider, price table and
  weekly multipliers are unchanged (`gemini-3.1-pro-high` and friends hit the existing
  Antigravity pricing entries directly).
- **Model-name join**: transcript rows carry no model name, so the scanner builds a run
  timeline from `log/cli-*.log` (local-time file names, the last `Resolving model` line
  per file) and joins each row's UTC timestamp into its run window. Rows without a hit
  still count and fall into the unnamed-model group; a failed join never blocks a scan.
- **Reasoning token character split**: the ledger has no native reasoning counter, so
  output is split into reasoning + output by the character share of the `thinking` field
  (the shared `ReasoningCharSplit` formula already used for MiniMax/DeepSeek); rows
  without thinking text stay pure output. reasoning + output always equals the raw
  output tokens.
- **DSH-grade scan guardrails**: a 1 GiB raw-byte / 1,024-file budget (newest-first
  truncation flags `isTruncated`), deduplication across the main transcript and its
  rolling chunks, fingerprint-cached incremental scans, and partial results never
  persisted to the cache. Agy scans run in their own batch, never overlapped with the
  other heavyweight parsers.

### Install

Download `LLM-monitor-1.23.0.dmg` from the release assets, drag **LLM-monitor.app** into
**Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is
ad-hoc signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

新增一个本地账本客户端：**Agy**——Antigravity 的 CLI 分支（`~/.gemini/antigravity-cli/`），
其明文会话 transcript 现作为独立客户端接入监视器。token 用量计入 Google Antigravity 卡，
与 IDE 账本同卡并列；模型名从 CLI 运行日志 join 回来，思考 token 用共享的字符占比公式从
output 中拆出。额度窗口与价格表零改动。

### 新增

- **新客户端 Agy（Antigravity 的 CLI 分支）**：每个会话落盘为
  `~/.gemini/antigravity-cli/brain/` 下的明文 JSONL transcript。设置 → Clients 自动出现
  Agy tab；其 token 计入 Google Antigravity 卡，与 IDE 本地账本并列。Provider、价格表与
  周倍率口径零改动（`gemini-3.1-pro-high` 等模型直接命中现有 Antigravity 价目）。
- **模型名 join**：transcript 行不带模型名，扫描器用 `log/cli-*.log` 构建运行时间线
  （文件名本地时区、每文件取最后一条 `Resolving model`），把每行的 UTC 时间 join 进所属
  运行窗口；无命中的行照常计入用量、归入未命名模型组，join 失败不阻断扫描。
- **思考 token 字符分摊**：账本没有原生 reasoning 计数，按 `thinking` 字段字符占比把
  output 守恒拆成 reasoning + output（复用 MiniMax/DeepSeek 的 ReasoningCharSplit 共享
  公式）；无思考文本全记 output，reasoning + output 恒等于原始 output_tokens。
- **DSH 同款扫描护栏**：1 GiB 原始字节 / 1024 文件预算（mtime 最新优先截断并置
  isTruncated）、主 transcript 与滚动分块跨文件去重、指纹缓存增量短路、partial 结果
  永不入缓存；Agy 扫描独立成批，不与其他大体积解析器重叠。

### 安装

从 Release 附件下载 `LLM-monitor-1.23.0.dmg`，将 **LLM-monitor.app** 拖入
**Applications**，并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开
如遇 Gatekeeper 拦截，请右键 →「打开」。
