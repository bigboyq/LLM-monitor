# LLM Monitor 1.23.1

[English](#english) · [简体中文](#简体中文)

## English

A patch release to 1.23.0 with one fix: the merged 「额度窗口」 table truncated large
weekly usage values on heavy-usage providers (MiniMax was the first to hit it).

### Fixed

- **Middle column truncation in the quota-window table**: weekly-row values like `1.22M`
  (用量 in 分析 mode, Cached in 用量 mode) rendered as `1.22…` — the four switching columns
  were 38pt wide while the widest realistic forms measure ~40pt (`100.0%` cache hit,
  `12.34M` tokens). They are now **42pt**, funded by tighter grid spacing (10→8pt) and a
  slimmer reset-date gutter (12→9pt); the reset date's text area keeps every point of its
  117pt worst-case width. A new guardrail test pins ≥2pt of margin for six compact token
  forms. See [1.23.0](1.23.0.md) for the segment switch and percent-format unification
  this table belongs to.

### Install

Download `LLM-monitor-1.23.1.dmg` from the release assets, drag **LLM-monitor.app** into
**Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is ad-hoc
signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

1.23.0 的补丁版本，只含一个修复：重额度 Provider（minimax 首先撞线）的「额度窗口」合并
表格截断大用量数值。

### 修复

- **额度窗口表格中间列截断**：周行的「用量」（分析态）与「Cached」（用量态）在 `1.22M`
  形态下显示成 `1.22…`——四个切换列原宽 38pt，而现实最宽形态实测约 40pt（命中列 `100.0%`、
  token `12.34M`）。现加宽到 **42pt**，宽度来自 Grid 横向间距 10→8pt 与重置日期前置
  gutter 12→9pt；重置日期文字区的 117pt 最坏情况宽度一分未减。新增护栏测试为六种 compact
  形态钉住 ≥2pt 余量。本表格所属的 segment 切换与百分比口径统一见 [1.23.0](1.23.0.md)。

### 安装

从 Release 附件下载 `LLM-monitor-1.23.1.dmg`，将 **LLM-monitor.app** 拖入 **Applications**，
并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开如遇 Gatekeeper 拦截，
请右键 →「打开」。
