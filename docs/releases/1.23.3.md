# LLM Monitor 1.23.3

[English](#english) · [简体中文](#简体中文)

## English

A maintenance release from a full project audit: no new user-facing features, but a batch of
fixes for frozen text, wasted work, privacy, and robustness — plus release tooling and docs
that can no longer drift silently.

### Fixed

- **Time text in the floating cards** (continuation of 1.23.2): the quota-window reset
  countdown, the reset-credit remaining time, and the card's "today" row now all read the
  host display clock, and the menu's own clock **stops when the menu closes** — it used to
  keep ticking every second (with a full menu re-render) for the whole process lifetime
  once the menu had been opened.
- **A refresh storm on every config write**: saving settings or dropping the dock panel
  re-fetched *every* provider immediately, each with the more expensive full-refresh
  semantics. Config reloads now keep unchanged providers' schedules and first-refresh state
  intact and only re-anchor what actually changed.
- **Bark device key could be written to `log.txt`**: the key lives in the request URL's path
  segment, and the oversized-response error echoed that path. Bark errors and logs now use a
  fixed `bark://<host>/<key prefix>…` label, with a test pinning that the key can never appear.
- **A missing resource bundle caused a launch-crash loop**: pricing and holiday rules now
  degrade loudly instead of crash-looping (models show as "unpriced", peak rules fall back to
  plain Mon–Fri). Present-but-corrupt resources still fail fast — that behavior is unchanged
  by design.
- **Edge dock could crash** on the "system reports zero screens" path (headless session /
  hot-unplug).
- **23 tests only passed on machines east of UTC** — the suite is green under
  `TZ=America/New_York` and `TZ=UTC` now.

### Improved

- **Cards no longer recompute once per second**: derived values (projection, quota-window
  usage, today row, 7-day cost) are memoized on their inputs, so the display-clock tick only
  compares keys. This matters on large local ledgers (tens of thousands of samples).
- **Quieter, safer internals**: notification baselines are written off the main thread (with a
  shutdown flush and a write floor so queued older snapshots can't regress the file); the
  menu's 30-second inactivity timer reuses a single handle; DSH decompression temp files live
  in the app-owned temp root and are swept at launch; subprocess output files are created
  owner-only (0600).

### Tooling & docs

- `build-release.sh` now refuses to build from a dirty worktree, or when `VERSION`,
  `CHANGELOG`, the READMEs and the release notes disagree — the drift that shipped a stale
  help doc in 1.23.2 is now gated, and `spec/config.md` lists the manual pre-release checks.
- `audit.sh` validates the arm64 binary that was actually just built (it used to inspect a
  stale artifact).
- Help and READMEs corrected (GLM's peak window is fixed Beijing time with statutory holidays
  excluded; how to learn about new versions), and `docs/releases/` gained an index that
  states its own gaps.

### Install

Download `LLM-monitor-1.23.3.dmg` from the release assets, drag **LLM-monitor.app** into
**Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is ad-hoc
signed; first launch needs macOS's own approval (macOS 15+: System Settings → Privacy &
Security → "Open Anyway"). The app never updates itself — watch the Releases page for new
versions.

## 简体中文

一次全项目审计后的维护版本：没有面向用户的新功能，而是一批修复——冻结的文案、白费的请求、
隐私与健壮性——外加不会再静默漂移的发布工具与文档。

### 修复

- **浮层卡片的时间文案**（1.23.2 的续修）：额度窗口「重置日期」倒计时、reset 卡剩余时间、
  卡片「今」行全部改读宿主展示时钟；**菜单展示时钟在关菜单时显式停表**——此前只挂
  `onDisappear`，而关菜单走 `orderOut` 不销毁视图，打开过一次菜单后 1 秒一次的 tick
  （连同整树重渲染）会常驻整个进程。
- **修掉「每次写 config 全员立即重抓」**：保存设置、拖动 dock 松手都会让所有 provider 立刻
  各重抓一遍（且因首刷状态被清而走更贵的 full 语义）。配置重载改走差异化重排：未变的
  provider 保留既有 deadline 与首刷状态，只重锚真正变化的那几个。
- **Bark Device Key 可能落进 `log.txt`**：key 在请求 URL 的 path 段，超限错误的文案会回显该
  path。Bark 的日志与错误定位改用固定标签 `bark://<host>/<key 前 4 位>…`，并加测试钉住
  key 不可能出现。
- **资源 bundle 缺失不再启动即崩**：定价与节假日规则降级并记 error（全部模型显示「未定价」、
  高峰判定回退纯周一–周五）。bundle 在而 JSON 坏仍按原设计 fail-fast，这一点未变。
- **边缘状态窗在「系统零屏幕」路径上可能越界崩溃**（无头会话 / 显示器热拔）。
- **23 条只在非负 UTC 偏移机器上成立的测试**已修——`TZ=America/New_York` 与 `TZ=UTC` 下
  全绿。

### 改进

- **卡片不再每秒重算**：投影 / 额度窗口快照 / 「今」行 / 7 天金额按输入值键 memo，展示时钟
  tick 只做键比较。对本地账本很大的用户（数万条样本）感受最明显。
- **更低损耗、更稳的内部行为**：通知基线写盘移出主线程（停机同步兜底 + 写高水位防回退）；
  菜单 30 秒无交互计时器改为单句柄复用；DSH 解压临时文件落 App 自有临时根并在启动时回收；
  子进程产出文件以 0600 出生。

### 工具与文档

- `build-release.sh` 新增发布门禁：工作区不干净、或 `VERSION` / `CHANGELOG` / 两份 README /
  版本说明文档四处不一致时拒绝出包——1.23.2 那次「帮助文档口径过期仍发布」的漂移类型现在
  被门禁挡住，`spec/config.md` 同时列出了人工发布前检查清单。
- `audit.sh` 改校验**本次真实构建**的 arm64 产物（此前在校验一个一个月前的陈旧二进制）。
- 帮助与 README 口径修正（GLM 高峰窗口为固定北京时间、法定节假日除外；新增「如何获知新版本」）；
  `docs/releases/` 新增索引并如实标注自身记录断档。

### 安装

从 Release 附件下载 `LLM-monitor-1.23.3.dmg`，将 **LLM-monitor.app** 拖入 **Applications**，
并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开需在系统设置里放行
（macOS 15+：系统设置 → 隐私与安全性 → 「仍要打开」）。应用不会自动更新——请留意 Releases 页。
