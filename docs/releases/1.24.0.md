# LLM Monitor 1.24.0

[English](#english) · [简体中文](#简体中文)

## English

This release adds hub-and-node sync so several Macs can view their local usage together.

### Hub-and-node usage sync

- Configure one Mac as the hub and one or more Macs as nodes under **Settings → Multi-device**.
- The hub aggregates node usage reports. Nodes periodically send usage and quota snapshots, and reconnect after temporary network failures.
- Switch the main menu and provider cards between global, local, and individual-node views. Offline nodes retain their last successful snapshot and are marked stale.
- The settings pane shows the hub's LAN address, connection status, and connected nodes. Node names, listening port, and reporting interval are configurable.
- The topology is one level deep: nodes do not relay reports to other nodes.

### Network note

The current sync protocol uses HTTP without TLS or application-level authentication. Use it only on a trusted LAN. For plain HTTP, use the hub's LAN IP address or a `.local` hostname; macOS App Transport Security may block a regular fully qualified domain name even when it resolves to a private address.

## 简体中文

本版本新增主副节点联动，可在多台 Mac 之间汇总并查看各自的本地用量。

### 主副节点用量联动

- 在「设置 → 多机联动」将一台 Mac 配置为主节点，其余设备配置为一个或多个副节点。
- 主节点汇总副节点上报的数据；副节点定期发送用量与额度快照，临时断网后会继续尝试连接。
- 主菜单和 Provider 卡片支持切换全局、本机或单个节点视图。节点离线时保留最后一次成功同步的数据，并标记为过期。
- 设置页展示主节点局域网地址、连接状态和已连接节点；可配置节点名称、监听端口与上报频率。
- 拓扑为单层结构，副节点不会继续转发数据。

### 网络说明

当前同步协议使用 HTTP，尚未提供 TLS 或应用层认证，仅建议在可信的局域网内使用。明文 HTTP 建议填写主节点内网 IP 或 `.local` 主机名；即使普通完整域名解析到内网地址，macOS App Transport Security 仍可能拦截连接。
