# LLM Monitor 1.4.0

[English](#english) · [简体中文](#简体中文)

![LLM Monitor menu bar dashboard](https://raw.githubusercontent.com/bigboyq/LLM-monitor/main/docs/images/menu-overview.png)

## English

This release publishes the current LLM Monitor snapshot as a universal macOS menu bar app for Apple Silicon and Intel Macs.

### Highlights

- Monitor Minimax, ChatGPT/Codex, Antigravity, GLM Coding Plan, and DeepSeek in one menu.
- Merge local OpenCode usage independently for each supported provider.
- View local token totals and seven-day charts from Codex, Minimax v2, Antigravity RPC, and ZCode.
- See GLM and DeepSeek peak-period indicators, quota reset details, and system health in the menu bar.
- Benefit from hardened refresh scheduling, local cache recovery, scanner cancellation, and configuration handling.

### Install

Download `LLM-monitor-1.4.0.dmg`, verify it with `SHA256SUMS.txt`, and drag the app to `/Applications`.

This snapshot is ad-hoc signed and not Apple-notarized. If macOS blocks the first launch, Control-click the app in Finder and choose **Open**. See the [English user guide](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.en.md) for setup and troubleshooting.

## 简体中文

本版本将 LLM Monitor 当前 snapshot 发布为同时支持 Apple Silicon 和 Intel Mac 的 universal 菜单栏应用。

### 主要更新

- 在一个菜单中监控 Minimax、ChatGPT/Codex、Antigravity、GLM Coding Plan 与 DeepSeek。
- 每个 Provider 可独立选择是否合并 OpenCode 本地用量。
- 汇总 Codex、Minimax v2、Antigravity RPC 与 ZCode 的本地 token，并展示最近七天图表。
- 增加 GLM/DeepSeek 高峰提示、额度重置详情和状态栏健康度。
- 加固刷新调度、缓存恢复、scanner 取消和配置文件处理。

### 安装

下载 `LLM-monitor-1.4.0.dmg`，使用 `SHA256SUMS.txt` 校验后，把应用拖到 `/Applications`。

当前 snapshot 使用 ad-hoc 签名，未经过 Apple notarization。若 macOS 阻止首次启动，请在 Finder 中右键应用并选择“打开”。配置和故障排除请参阅[中文帮助](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.zh-CN.md)。
