# LLM Monitor 1.4.1

[English](#english) · [简体中文](#简体中文)

![LLM Monitor menu bar dashboard](https://raw.githubusercontent.com/bigboyq/LLM-monitor/main/docs/images/menu-overview.png)

## English

This patch release fixes a menu bar rendering issue while retaining all features introduced in 1.4.0.

### Fixed

- Replaced the periodic `TimelineView` inside the `MenuBarExtra` label with a stable minute clock managed by `AppState`.
- Prevented a status-item redraw loop that could cause high CPU usage and growing memory consumption on some macOS versions.
- Preserved minute-level updates for GLM and DeepSeek peak-period health indicators.

### Install

Download `LLM-monitor-1.4.1.dmg`, verify it with `SHA256SUMS.txt`, and drag the app to `/Applications`.

This build is ad-hoc signed and not Apple-notarized. If macOS blocks the first launch, Control-click the app in Finder and choose **Open**. See the [English user guide](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.en.md) for setup and troubleshooting.

## 简体中文

本补丁版本修复菜单栏渲染问题，并完整保留 1.4.0 的全部功能。

### 修复

- 将 `MenuBarExtra` 标签内的周期性 `TimelineView` 替换为由 `AppState` 管理的稳定分钟时钟。
- 避免部分 macOS 版本中状态栏图标持续重绘，导致 CPU 占用过高和内存持续增长。
- 保留 GLM 与 DeepSeek 高峰时段健康度的分钟级更新。

### 安装

下载 `LLM-monitor-1.4.1.dmg`，使用 `SHA256SUMS.txt` 校验后，把应用拖到 `/Applications`。

当前版本使用 ad-hoc 签名，未经过 Apple notarization。若 macOS 阻止首次启动，请在 Finder 中右键应用并选择“打开”。配置和故障排除请参阅[中文帮助](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.zh-CN.md)。
