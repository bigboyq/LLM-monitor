# LLM Monitor 1.4.2

[English](#english) · [简体中文](#简体中文)

![LLM Monitor menu bar dashboard](https://raw.githubusercontent.com/bigboyq/LLM-monitor/main/docs/images/menu-overview.png)

## English

This release refines the menu bar experience, hardens refresh scheduling, and introduces local-usage notifications and brand icons. No new providers, no breaking schema changes — drop-in upgrade from 1.4.1.

### Highlights

- Optional right-corner health dot (green / orange / red) keeps the user-chosen menu bar icon intact.
- Local usage notifications when a model's remaining quota increases between consecutive refreshes.
- Brand icons for GLM, DeepSeek, and OpenCode, shared between menu cards and the settings page.
- Codex `rate_limit_reset_credits` now refreshes on every 20th background refresh (about every 100 minutes at the default 300 s interval), so reset-credit cards stay fresh without forcing an extra full refresh.
- Settings typography, section headers, and switch alignment have been reorganized for a more legible layout.
- Menu window height is bounded by `NSWindow.contentMaxSize` at 70% of the screen, replacing the previous SwiftUI frame-based budget that drifted on multi-monitor and Dock changes.
- "Stale" detection window is now `3 × (N × refreshInterval) ≈ 5 hours` instead of the previous 15-minute random threshold.
- Hardened initialization order avoids `UNUserNotificationCenter` crashes during early app startup; the bare SwiftPM executable safely disables notifications when no bundle identifier is present.

### Install

Download `LLM-monitor-1.4.2.dmg`, verify it with `SHA256SUMS.txt`, and drag the app to `/Applications`.

This build is ad-hoc signed and not Apple-notarized. If macOS blocks the first launch, Control-click the app in Finder and choose **Open**. See the [English user guide](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.en.md) for setup and troubleshooting.

## 简体中文

本版本优化菜单栏体验，加固刷新调度，新增本地用量通知和品牌图标。不引入新 Provider，不破坏配置 schema —— 从 1.4.1 平滑升级。

### 主要更新

- 保留用户选择的菜单栏主图标，可选的右下角健康圆点（绿 / 橙 / 红）单独表示系统健康度。
- 当模型剩余额度较上一次成功请求增加时，触发 macOS 系统通知。
- GLM、DeepSeek 与 OpenCode 品牌图标，菜单卡片与设置页统一使用。
- Codex reset credits 改为周期自动刷新（每 20 次 background 抓取补 1 次 full 抓取，约每 100 分钟），让重置卡这类只在 full 抓取里返回的字段保持新鲜，无需强制手动刷新。
- 重新整理设置窗口的字体层级、分区说明与控件对齐；布尔选项统一使用小尺寸 switch。
- 菜单窗口高度按内容决定，多于屏幕可见高度 70% 时由 `NSWindow.contentMaxSize` 封顶，避免多屏 / Dock 变化时拿到错误值。
- "可能过期"判定改为按 `3 × (N × 刷新间隔) ≈ 5 小时` 计算，移除原先 15 分钟随机误报。
- 延迟初始化系统通知中心，避免启动早期崩溃；裸 SwiftPM 可执行文件缺少 Bundle Identifier 时安全禁用通知。
- 状态栏主图标画布调整为 22pt，主图形 20pt，健康圆点 6pt。
- Codex local usage details schema 扩展（`recentSamples` 字段，把逐次调用样本带入 7 天柱图）。

### 安装

下载 `LLM-monitor-1.4.2.dmg`，使用 `SHA256SUMS.txt` 校验后，把应用拖到 `/Applications`。

当前版本使用 ad-hoc 签名，未经过 Apple notarization。若 macOS 阻止首次启动，请在 Finder 中右键应用并选择“打开”。配置和故障排除请参阅[中文帮助](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.zh-CN.md)。
