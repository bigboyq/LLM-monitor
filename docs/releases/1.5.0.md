# LLM Monitor 1.5.0

[English](#english) · [简体中文](#简体中文)

![LLM Monitor menu bar dashboard](https://raw.githubusercontent.com/bigboyq/LLM-monitor/main/docs/images/menu-overview.png)

## English

This release adds DeepSeek Harness (dsh) usage monitoring, a new per-client usage tab, a JSON-driven pricing catalog, and a faster dual-loop refresh architecture. The app bundle is now arm64-only and slimmed from 14.3 MB to 3.5 MB. Configuration schema v2 migrates automatically — drop-in upgrade from 1.4.2 on Apple Silicon Macs.

### Highlights

- New DeepSeek Harness (dsh) monitoring: JSONL session logs in `~/.dsh/sessions` (zstd / Node 22+ zlib) are split by provider in `request/context` and merged into the MiniMax / GLM / DeepSeek cards.
- New **Settings → Clients** tab: per-client local token usage (Antigravity / Codex / DSH / MiniMax Code / OpenCode / ZCode), seven-day bar charts, cache hit rate, and value estimated from public API prices. Unpriced models are listed explicitly instead of silently zeroed.
- Model pricing moved to a bundled `ModelPricing.json`: new GPT-6 Astra, updated GPT-5.6 Sol, Gemini 3.8 Flash / 3.1 Pro, GLM-5.3-Flash and DSH uncached-input / cache-read buckets; retired Gemini 2.5 and MiniMax M2 series (historical usage shows "unpriced" by design).
- Scheduler refactored into two loops: a quota loop for all providers and a usage loop for all six clients, decoupling quota success from local scans. Manual refresh and system wake trigger both loops immediately.
- Faster local scans: Codex parses only appended file tails within an app session (~12× faster cold scan), DSH skips noise lines at the byte level before JSON decoding, and the 256 MB byte budget is relaxed to 1 GB. DSH keeps parsed results for the 256 most recent sessions so historical files are not re-parsed every cycle.
- Repackaged for size: arm64-only build, stripped binary symbols (dSYM kept beside the app), and a de-duplicated, compressed icon.
- Fixed: Codex (ChatGPT) today/recent amounts showing `—`; mid-cycle supplementary refresh never firing on the regular refresh path; cached ZCode balances lingering after the activity/balance toggle is switched off; the eighth day leaking into the seven-day chart; ChatGPT card now includes merged OpenCode usage in hover details; MiniMax (DSH) uncached input showing `0`; DSH MiniMax-M3 reasoning tokens showing `0`.
- DeepSeek peak windows are now fixed to the official Beijing-time schedule (weekdays 9:00–12:00 / 14:00–18:00); the "weekdays only" setting was removed and its stale config key is ignored.

### Install

Download `LLM-monitor-1.5.0.dmg`, verify it with `SHA256SUMS.txt`, and drag the app to `/Applications`. This build requires Apple Silicon (arm64).

This build is ad-hoc signed and not Apple-notarized. If macOS blocks the first launch, Control-click the app in Finder and choose **Open**. See the [English user guide](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.en.md) for setup and troubleshooting.

## 简体中文

本版本新增 DeepSeek Harness (dsh) 用量监控、按客户端维度的用量 tab、JSON 化的价目目录，并重构为更快的双循环刷新架构。安装包改为 arm64-only，体积从 14.3MB 降到 3.5MB。配置 schema v2 自动迁移 —— Apple Silicon Mac 上可从 1.4.2 平滑升级。

### 主要更新

- 新增 DeepSeek Harness (dsh) 监控：扫描 `~/.dsh/sessions` 中的 JSONL session 日志（zstd / Node 22+ zlib 双解压路径），按 `request/context` 中的 provider 分片，自动合并到 MiniMax / GLM / DeepSeek 卡片。
- 新增"设置 → 客户端"tab：按客户端维度展示本地 token 用量（Antigravity / Codex / DSH / MiniMax Code / OpenCode / ZCode）、最近 7 天柱图、缓存命中率与按公开 API 单价估算的价值；未定价模型显式列出名称与调用量，不再静默归零。
- 模型价格目录 JSON 化：价格数据迁移到随 app 打包的 `ModelPricing.json`；新增 GPT-6 Astra、Gemini 3.8 Flash / 3.1 Pro、GLM-5.3-Flash 与 DSH 独立 uncached-input / cache-read 计价，更新 GPT-5.6 Sol 价格；退休 Gemini 2.5 与 MiniMax M2 系列（历史用量显示"未定价"，有意行为）。
- 调度重构为「双循环」：额度循环管理全部 Provider 抓取，用量循环按全局间隔迭代 6 个客户端，彻底解耦 quota 成功对本地扫描的触发；手动刷新与系统唤醒同时触发双循环。
- 本地扫描提速：Codex 在程序生命周期内只解析会话文件新增尾部（冷扫描约 12× 提速）、DSH 在字节层跳过噪声行再进 JSON 解码，字节总预算从 256MB 放宽到 1GB；DSH 保留最新 256 个会话的解析缓存，历史文件不再每轮重解压。
- 打包瘦身：arm64-only、二进制 strip 符号表（dSYM 保留在 .app 外用于崩溃符号化）、图标去重与压缩，`.app` 从 14.3MB 降到 3.5MB。
- 修复：Codex (ChatGPT) 今日与近几日金额显示 `—`；常规刷新路径的 mid-cycle 补刷新从未生效；关闭 ZCode「活动/余额解析」开关后余额残留；第 8 天样本漏进七天柱图；ChatGPT 卡片 hover 明细补齐合并的 OpenCode 用量；MiniMax (DSH) 未缓存输入显示 `0`；DSH 路由 MiniMax-M3 时 reasoning token 显示 `0`。
- DeepSeek 高峰时段固定为官方口径（北京时间周一至周五 9:00–12:00 与 14:00–18:00，周末全天平价），移除「仅工作日」开关，旧配置键静默忽略。

### 安装

下载 `LLM-monitor-1.5.0.dmg`，使用 `SHA256SUMS.txt` 校验后，把应用拖到 `/Applications`。本版本仅支持 Apple Silicon (arm64)。

当前版本使用 ad-hoc 签名，未经过 Apple notarization。若 macOS 阻止首次启动，请在 Finder 中右键应用并选择"打开"。配置和故障排除请参阅[中文帮助](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.zh-CN.md)。
