# LLM Monitor 1.6.0

[English](#english) · [简体中文](#简体中文)

## English

This release introduces a fully parameterized dynamic SVG status bar dashboard, transforming the app menu bar icon into a real-time visual gauge for week quotas, 5-hour quotas, and bottle-neck quota water levels.

### Highlights

- **Dynamic Vector Status Bar Dashboard**: The app icon is now rendered on-the-fly via a parameterized vector SVG engine (`QuotaLogoSVGBuilder`), completely replacing previous static icons.
- **Dual Quota Rings (Week & 5h)**:
  - **Outer Ring**: Reflects the weekly quota availability ($\min$ and average across active models).
  - **Middle Ring**: Reflects the 5-hour quota availability ($\min$ and average).
- **Counter-Clockwise Sweep (Left Support, Right Breathing Room)**:
  - Arcs sweep counter-clockwise starting from 12 o'clock.
  - The solid arc ($0 \to \min$) wraps the left half of the ring for solid visual anchoring.
  - The dashed arc ($\min \to \text{avg}$) curves smoothly along the bottom to bottom-right.
  - The remaining empty space ($100\%$) rests on the right/top-right.
- **2-4-2 Calibrated Dash Scale**: Precision calibrated `stroke-dasharray="32 64"` (2 physical pixels solid + 4 physical pixels gap on Retina displays) for optimal breathing room and crisp meter readability.
- **Strict Water Level & Alert Hierarchy**:
  - Center cup water level directly reflects the lowest remaining 5-hour quota.
  - Prioritized health color state machine (Red > Yellow > Green):
    - **Red**: Any 5h quota $< 10\%$ or average 5h quota $< 40\%$.
    - **Yellow**: Any 5h quota $< 40\%$, active peak pricing window (GLM / DeepSeek), or average 5h quota $< 60\%$.
    - **Green**: Default healthy baseline.
- **Performance & Zero Redundant Refreshes**:
  - `MenuBarLabel` caches composite images using a 7-factor `RenderSignature` to guarantee zero re-rendering when inputs remain unchanged.
  - Subscribed to minute-boundary health clock ticks to accurately transition on peak pricing boundaries without redundant redraws.
  - Removed obsolete static menu bar SVG files from disk and bundle configuration.

### Install

Download `LLM-monitor-1.6.0.dmg`, verify it with `SHA256SUMS.txt`, and drag the app to `/Applications`. This build requires Apple Silicon (arm64).

This build is ad-hoc signed and not Apple-notarized. If macOS blocks the first launch, Control-click the app in Finder and choose **Open**. See the [English user guide](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.en.md) for setup and troubleshooting.

## 简体中文

本版本将菜单栏状态栏图标全面升级为参数化动态矢量仪表盘，外圈（周额度）与中圈（5h 额度）以双环形态精准展现配额池水位，并引入逆时针构型与 2-4-2 呼吸感刻度。

### 主要更新

- **参数化动态矢量仪表盘**：状态栏 App 图标全面接入 `QuotaLogoSVGBuilder` 矢量引擎，完全替代原有静态切图，随模型额度变化毫秒级动态渲染。
- **双环多维额度呈现**：
  - **外圈（周额度）**：展示有效模型周配额真实物理剩余百分比（实线保底最小值 $\min$，虚线到均值 $\text{avg}$）。
  - **中圈（5h 额度）**：展示有效模型 5 小时短周期额度的真实物理剩余百分比。
- **逆时针弧形美学设计**：
  - 以 12 点钟为起点逆时针展开；
  - $0 \to \min$ 实线段稳定承托左半环，$\min \to \text{avg}$ 虚线段沿底部延伸至右下，剩余空白位于右侧与右上方，兼具力量感与通透呼吸感。
- **2-4-2 呼吸感刻度标定**：虚线步长精确标定为 `stroke-dasharray="32 64"`，在 macOS Retina 屏（@2x）上对应 2 像素实线与 4 像素留白，虚线点阵疏密有致，彻底告别粘连与毛刺。
- **中心水位三级警报与高峰感知**：
  - 中心水杯水位直观映射 5h 最低剩余可用量。
  - 水体颜色严格遵循「红 > 黄 > 绿」优先级判定：
    - **红色**：任意 5h 额度 $< 10\%$ 或 5h 均值 $< 40\%$。
    - **黄色**：任意 5h 额度 $< 40\%$、处于高峰价格窗口（GLM / DeepSeek）、或 5h 均值 $< 60\%$。
    - **绿色**：基准健康状态。
- **渲染性能与零多余刷新**：
  - `MenuBarLabel` 引入 7 维全要素 `RenderSignature` 签名缓存，仅在可见数据实质改变时合成图像，杜绝反复重绘。
  - 接入分钟时钟监听，在高峰时段切换点自动无缝变色。
  - 清理工程内 4 个无用旧版静态 SVG 文件，移除磁盘 I/O 依赖。

### 安装

下载 `LLM-monitor-1.6.0.dmg`，使用 `SHA256SUMS.txt` 校验后，把应用拖到 `/Applications`。本版本仅支持 Apple Silicon (arm64)。

当前版本使用 ad-hoc 签名，未经过 Apple notarization。若 macOS 阻止首次启动，请在 Finder 中右键应用并选择“打开”。配置和故障排除请参阅[中文帮助](https://github.com/bigboyq/LLM-monitor/blob/main/docs/help.zh-CN.md)。
