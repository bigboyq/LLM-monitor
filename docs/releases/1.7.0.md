# LLM Monitor 1.7.0

[English](#english) · [简体中文](#简体中文)

## English

This release turns quota notifications into a fully user-configurable module: four quota
events per windowed provider, an independent channel per event (system notification or
Bark push), a hardened Bark transport, and detection baselines that survive relaunches.

### Highlights

- **Four Quota Events with Independent Channels**: 5-hour / weekly × restored / exhausted.
  Each windowed provider (ChatGPT/Codex, GLM, Minimax, Antigravity) configures every event's
  channel separately in its settings pane: off, system notification, or Bark + system.
  Default channels preserve the historical behavior (restored → system, exhausted → off); the restored thresholds themselves are new, see the next bullet.
- **Deterministic Trigger Semantics**: "restored" fires when the remaining share rises by
  more than 5 percentage points or climbs back above 98%; "exhausted" is a one-shot edge
  trigger when it crosses below ~0%. Edge detection baselines are persisted to
  `notification-state.json`, so exhaustion/recovery events that happen while the app is
  closed are reported once on the first refresh after relaunch instead of being silently
  dropped.
- **Bark Push Channel**: official `api.day.app` or self-hosted servers (base paths kept for
  reverse proxies), POST JSON transport (no URL-encoding limits), masked device-key input,
  optional sound, group, and message TTL (seconds — pushes with a positive TTL are
  automatically deleted from the phone once expired; empty/0 omits the parameter), and a
  test-push button that reuses the exact production path.
- **Stable Overwrite IDs**: Bark pushes carry a per provider+model `id`, so a new push
  replaces the previous one on your phone instead of piling up (Bark v1.5.2+ /
  bark-server v2.2.5+).
- **"At the Mac" Skip Policy**: with one toggle, Bark is skipped while the display is awake
  and the session is unlocked — you already see system notifications; display sleep or a
  locked screen (user away) always delivers.
- **Production-Grade Send Queue**: serial actor queue with bounded backlog (overflow merges
  per model, keeping the newest), a 60-second per-model cooldown on both channels (successful
  sends only), one retry on server/transient network errors, and full cancellation on quit.
- **System Notification Polish**: titles now reflect the event kind (「额度已用完 /
  已恢复 / 额度提醒」), and macOS notification threads include the provider dimension so
  same-named models from different providers never merge.

DeepSeek remains balance-based and does not participate in window triggers; a balance
threshold trigger is planned future work.

### Install

Download `LLM-monitor-1.7.0.dmg` from the release assets, drag **LLM-monitor.app** into
**Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is
ad-hoc signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

本版本把额度通知升级为完全可配置的标准模块：每个窗口类 Provider 细分四类额度事件、
每类事件独立选择通知渠道（系统通知或 Bark 推送）、Bark 传输层生产级加固，且事件检测
基线跨重启持久化。

### 主要更新

- **四类额度事件 × 独立渠道**：5 小时 / 周额度 × 恢复 / 耗尽。ChatGPT/Codex、GLM、
  Minimax、Antigravity 四个窗口类 Provider 在各自设置页独立配置每类事件的渠道：
  不通知、系统通知、Bark + 系统通知；渠道默认与历史行为一致（恢复 → 系统通知，
  耗尽 → 不通知）。
- **确定性的触发语义**：「恢复」= 剩余比例回升超过 5 个百分点，或回到 98% 以上；
  「耗尽」为下穿约 0% 的一次性边沿触发。检测基线持久化到 `notification-state.json`，
  应用关闭期间发生的耗尽 / 恢复事件会在启动后第一次刷新时补报，不再静默丢失。
- **Bark 推送渠道**：支持官方 `api.day.app` 与自建服务端（保留反向代理子路径）、
  POST JSON 传输（无 URL 编码与长度限制）、掩码输入的 Device Key、可选铃声、分组
  与消息有效期 TTL（秒；> 0 时过期后手机端自动删除该消息，留空或 0 不携带参数），
  并提供与正式推送完全同路径的「发送测试推送」。
- **稳定覆盖 ID**：Bark 推送按 Provider + 模型生成稳定 `id`，同一模型的新推送覆盖
  手机上的旧通知，不再堆积历史提醒（需 Bark v1.5.2+ / bark-server v2.2.5+）。
- **「人在电脑前时跳过推送」**：一个开关——屏幕亮着且未锁屏时跳过 Bark（此时看得到
  系统通知）；显示器休眠或已锁屏（人不在）都正常推送。
- **生产级发送队列**：actor 串行队列、有界积压（超限按模型合并保留最新）、系统通知
  与 Bark 均有同模型 60 秒冷却（仅成功发送占用）、5xx / 网络瞬断自动重试一次、
  退出时取消未完成推送。
- **系统通知打磨**：标题按事件类型显示「额度已用完 / 已恢复 / 额度提醒」；通知线程
  引入 Provider 维度，不同 Provider 的同名模型不会串进同一线程。

DeepSeek 为余额口径，不参与窗口触发器；「余额低于阈值」触发器为规划中的后续特性。

### 安装

从 Release 附件下载 `LLM-monitor-1.7.0.dmg`，将 **LLM-monitor.app** 拖入
**Applications**，并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，
首次打开如遇 Gatekeeper 拦截，请右键 →「打开」。
