# LLM Monitor 1.8.0

[English](#english) · [简体中文](#简体中文)

## English

This release introduces the **Energy & Sleep Health** management module: live detection of sleep-inhibiting background processes and power configurations, a quick one-click keep-awake mode in the menu bar footer, and native IOKit integration.

### Highlights

- **Menu Bar Quick Keep-Awake Toggle**: A "节能" (Energy) button in the menu footer with a real-time tri-color status dot (Green = healthy sleep, Yellow = sleep inhibited by background apps or settings, Red = keep-awake mode active). One click temporarily keeps your Mac awake during long batch tasks or model training.
- **Safe In-Memory Assertion**: The keep-awake mode uses a memory-backed power assertion (`NoIdleSleepAssertion`) that automatically releases when the app exits or restarts. It never alters persistent system `pmset` configurations.
- **Dedicated Energy Settings Tab**: Full diagnosis of sleep health status, dual-warning reporting, detailed list of offending processes (process name, PID, assertion type, and real-time elapsed duration), and remediation guidance when AC sleep is disabled (`sleep = 0`).
- **Power Management Matrix**: Structured overview of key macOS power parameters (`sleep`, `womp`, `tcpkeepalive`, `powernap`, `displaysleep`) under both AC Power and Battery, paired with GUI and `pmset` CLI adjustment instructions.
- **Zero-Subprocess Native IOKit C API**: Direct kernel-level power preferences inspection via `IOPMCopyPMPreferences` and assertion queries via `IOPMCopyAssertionsByProcess`, achieving sub-millisecond query speed with zero subprocess overhead and zero regex/string-splitting fragility.
- **Unified Scheduling**: Sleep health diagnostics remain on the Provider scheduler's
  lifecycle, while local usage is reconciled after settled Provider batches and invalidated
  by scanner-owned FSEvents instead of a second polling timer.

### Install

Download `LLM-monitor-1.8.0.dmg` from the release assets, drag **LLM-monitor.app** into
**Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is
ad-hoc signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

本版本推出**「节能」系统睡眠健康度诊断与防休眠管理模块**：全面感知阻止 macOS 休眠的后台进程与电源配置风险，主菜单底部一键防休眠切换，并直通 IOKit 原生内核级接口。

### 主要更新

- **主菜单底部快捷「防休眠」开关**：主面板 Footer 新增「节能」按钮及实时三色健康状态指示灯（绿色 = 休眠健康，黄色 = 存在应用阻止休眠或电源配置告警，红色 = 已激活防休眠）。一键就地开启防休眠，保障长耗时训练或批处理任务不被中断。
- **纯内存安全断言**：防休眠采用轻量级系统断言（`NoIdleSleepAssertion`），App 退出或系统重启自动安全复位，绝不篡改系统持久化 `pmset` 电源配置，安全无后患。
- **设置页「节能」专属诊断面板**：展示系统睡眠健康度评估、双重告警机制（同时存在违规应用与 `ac_sleep = 0` 配置时双警齐发）、阻止休眠的违规应用明细（进程名、PID、断言类型与实时持续时长）以及系统级修复引导。
- **电源参数矩阵表**：结构化展示 `sleep`、`womp`、`tcpkeepalive`、`powernap`、`displaysleep` 在电源适配器（AC）与电池供电下的当前生效取值，并提供系统设置 GUI 与 `pmset` 命令行操作指引。
- **直通 IOKit 原生 C API**：通过 `IOPMCopyPMPreferences` 与 `IOPMCopyAssertionsByProcess` 亚毫秒级直接读取内核电源配置字典与活动断言，彻底消除子进程开销与命令行输出字符解析脆弱性。
- **调度归一化**：移除 LocalUsage 独立轮询定时器；本地用量在 Provider 批次结算后
  进行首次/日切全量扫描，其余由各 scanner 自持的 FSEvents dirty 状态驱动增量扫描。

### 安装

从 Release 附件下载 `LLM-monitor-1.8.0.dmg`，将 **LLM-monitor.app** 拖入
**Applications**，并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，
首次打开如遇 Gatekeeper 拦截，请右键 →「打开」。
