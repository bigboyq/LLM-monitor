# LLM Monitor 1.9.0

[English](#english) · [简体中文](#简体中文)

## English

This release introduces a redesigned quota dashboard in the macOS menu bar, event-driven local usage monitoring, and a more reliable refresh and packaging pipeline.

### Highlights

- **At-a-glance quota dashboard**: The left arc shows the 5-hour window and the right arc shows the weekly window. The center sector expands from 0° to 360° using the lowest currently available quota percentage, without a numeric label.
- **Prioritized health indicators**: Up to three bottom dots summarize active model health in strict red → yellow → green order. The top indicator mirrors Energy/Sleep Health.
- **Consistent status semantics**: Dashboard colors use the fixed quota health thresholds and handle missing windows explicitly, so time-to-reset factors and unsupported windows cannot distort the icon.
- **Event-driven local usage**: Scanner-owned FSEvents watchers wake only the affected local usage source, while initial, day-boundary, and configuration-change reconciliations retain full-scan correctness.
- **Unified deadline scheduling**: Regular Provider refreshes, reset-time supplementary refreshes, and sleep-health updates share cancellable deadline-driven scheduling with duplicate wake-up coalescing.
- **Stable menu layout**: The menu window follows its measured content within the current screen's visible height. The 360pt footer remains on one line without unnecessary flexible spacing.
- **Reliable release packaging**: The build script asks SwiftPM for the current products directory, preventing stale binaries or resource bundles from being packaged when build layouts change.

### Install

Download `LLM-monitor-1.9.0.dmg` from the release assets, drag **LLM-monitor.app** into **Applications**, and verify the SHA-256 checksum against `SHA256SUMS.txt`. The build is ad-hoc signed; right-click → Open on first launch if Gatekeeper asks.

## 简体中文

本版本重新设计了 macOS 状态栏额度仪表盘，并将本地用量监听与刷新调度升级为事件驱动架构，同时修复构建流程可能误打包旧二进制的问题。

### 主要更新

- **额度仪表盘一眼可读**：左侧弧线显示 5 小时额度，右侧弧线显示周额度；中心扇形按当前最紧张额度的剩余百分比在 0°～360° 动态展开，不显示数字。
- **状态点按风险优先**：底部最多三个状态点，严格按红 → 黄 → 绿排序汇总活跃模型健康度；顶部状态点同步显示节能/睡眠健康度。
- **状态语义统一**：图标颜色统一使用固定额度健康阈值，并明确处理缺失窗口，避免 reset 剩余时间或不支持窗口的模型错误影响颜色。
- **本地用量事件驱动**：每个扫描源通过 FSEvents 只唤醒受影响的扫描器，同时在首次运行、跨日和配置变化时保留完整扫描校准。
- **统一截止时间调度**：Provider 常规刷新、reset-time 补刷新与睡眠健康检查共用可取消的 deadline driver，相同截止时间的唤醒自动合并。
- **稳定的菜单布局**：菜单窗口依据真实内容和当前屏幕可见高度动态调整；Footer 保持 360pt 宽度并固定为单行，不再保留多余弹性空白。
- **可靠的发布打包**：构建脚本直接查询 SwiftPM 本次构建的实际产物目录，避免 toolchain 改变目录布局后误打包残留的旧二进制或资源包。

### 安装

从 Release 附件下载 `LLM-monitor-1.9.0.dmg`，将 **LLM-monitor.app** 拖入 **Applications**，并核对 `SHA256SUMS.txt` 中的 SHA-256。安装包为 ad-hoc 签名，首次打开如遇 Gatekeeper 拦截，请右键 →「打开」。
