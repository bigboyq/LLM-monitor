# LLM Monitor 2.2.0

[English](#english) · [简体中文](#简体中文)

## English

This release introduces ChatGPT API credits monitoring, fixes menu clock resumption, enhances 7-day usage chart layouts, and polishes settings page ergonomics.

### ChatGPT API credits monitoring

- Configure your OpenAI admin API key, monthly credit limit, billing day, and reset time in Settings under ChatGPT.
- The ChatGPT card now displays a full-width segmented progress bar with an indicator marker showing billing period time progress, alongside used, remaining, and cycle expiration information.

### Display clock and countdown fixes

- Fixed an issue where reopening the menu would leave quota reset countdowns frozen at the time the menu was previously closed. Reopening now immediately synchronizes with current system time and resumes the 1-second tick loop.
- Added clock synchronization when receiving route changes in standalone detail windows.

### Usage history and chart responsive layout

- Seven-day usage charts now support both compact (fixed 420pt for menu and hover panels) and expanded layouts (expanding to fill the available space in Settings and standalone windows).
- Increased font size and contrast for chart axis scales and date labels from tertiary to secondary.
- Renamed the menu disclosure action from "套餐历史" to "用量历史" (Usage History) for clarity.

### Settings page improvements

- Switching tabs in Settings now automatically resets the scroll position to the top, eliminating inherited scroll offsets, while preserving targeted scrolling when editing provider notification rules.
- Streamlined Edge Dock description text and moved detailed mechanics into a "Learn more…" popover.
- Compacted ChatGPT API credits settings spacing by removing redundant dividers.

## 简体中文

本版本带来 ChatGPT API 赠金监测、修复菜单时钟与倒计时恢复、升级 7 天用量历史空间自适应布局，并全面优化设置页交互细节。

### ChatGPT API 赠金监测

- 在「设置 → ChatGPT」中配置 Admin API Key、每月赠金额度、账单日与重置时间。
- ChatGPT 卡片新增通栏双色额度进度条与账期时间标记小三角，单行紧凑展示当月已用、剩余额度与周期截止倒计时。

### 展示时钟与倒计时唤醒修复

- 修复关闭菜单后重新打开时，重置倒计时停留在旧时间的问题。菜单每次打开瞬间即刻同步系统墙钟并恢复 1 秒轮询任务。
- 独立详情窗口在外部路由跳转时同步重对齐时钟。

### 用量历史图表空间自适应与排版提升

- 七天历史图表新增紧凑模式（菜单与悬浮窗维持 420pt）与宽松模式（设置页与独立详情窗口自适应全宽并拉开间距与字号）。
- 坐标轴刻度与横轴日期标签提级至 10–11pt 与 secondary 配色，突出核心读图信息。
- 菜单展开入口统一定名为「用量历史」，消除与套餐详情的歧义。

### 设置页体验与排版优化

- 设置页切换 Tab 自动复位至页面顶部，避免继承上一页的向下滚动偏移；同时保留从 Provider 页跳转编辑通知规则的定向滚动。
- 边缘状态窗大段说明精简为 2 句核心指引，双环与多屏机制移入「了解更多…」Popover 弹窗。
- 移除了 API 赠金设置项之间的冗余分割线，行间距与常规设置保持一致。
