# LLM Monitor 2.3.11

## English

Renames and reorders the usage metric columns to `Turns · Token · Hit · Think · Speed · Value · Update` (Pmt becomes Turns, Value moves after Speed, the scan time joins the header as Update). Data rows and the column header share the new order; the Update slot is widened to fit its title.

## 简体中文

用量指标列更名并重排为 `Turns · Token · Hit · Think · Speed · Value · Update`（Pmt 更名 Turns，Value 移到 Speed 之后，扫描时间以 Update 加入标题行）；数据行与列标题同步新序，Update 列加宽以容纳标题。
