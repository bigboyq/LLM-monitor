# LLM Monitor 2.3.12

## English

Makes the provider detail window adaptive to resizing: the minimum width is now derived from the `.expanded` seven-day history table (466pt table plus two padding layers = 514pt, previously 468pt clipped the last column at the window edge), and the default height grows to 880pt to fit both cards. Enlarging the window now stretches the seven-day history table and the quota-window table columns to fill the available width (key fixed columns such as reset dates stay put), and the ideal-size constraints that fought manual resizing are removed.

## 简体中文

Provider 详情窗口支持自适应缩放：窗口最小宽改为按 `.expanded` 7 天历史表格列宽推导（466pt 表格 + 两层 padding = 514pt，此前 468pt 装不下、最后一列被右缘裁掉），默认高提到 880pt 放得下两张卡。放大窗口时 7 天历史表格与额度窗口表格列随窗口弹性填满可用宽度（重置日期等关键列保持固定），并移除与手动缩放打架的 ideal 尺寸约束。
