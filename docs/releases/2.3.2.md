# LLM Monitor 2.3.2

[English](#english) · [简体中文](#简体中文)

## English

- Gemini quota conversion now uses an exact weekly-to-5-hour capacity ratio of 3.5, with a confirmed weekly allowance of $100.
- OpenAI API credit rows display each key's configured name. Unnamed keys use an API Key number, and Settings labels the field “Key 名称”.
- GLM and DeepSeek show a consistent peak multiplier, defaulting to 2× relative to off-peak 1×. Provider JSON can override `peakWindow.slots`, `weekdaysOnly`, and `multiplier`; Settings displays the current values without editing controls.
- DeepSeek local and Fleet cost estimates use the configured peak schedule and multiplier. GLM's nominal value estimates remain independent of peak-time credit consumption.

## 简体中文

- Gemini 周额度确认 $100，周 / 5h 容量换算改为精确 3.5 倍，分段条与有效剩余额度同步更新。
- OpenAI API 赠金按对应 Key 名称显示；未命名时显示 API Key 序号，设置页将名称字段明确标为「Key 名称」。
- GLM 与 DeepSeek 统一展示高峰倍率，默认高峰 2×、平时 1×。支持通过 Provider JSON 的 `peakWindow.slots`、`weekdaysOnly`、`multiplier` 配置时段、工作日限制与倍率；设置页只读展示当前值。
- DeepSeek 本地与 Fleet 金额估算均使用配置的高峰时段与倍率；GLM 的名义价值估算仍独立于积分峰谷扣费。
