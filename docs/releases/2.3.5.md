# LLM Monitor 2.3.5

## English

The off-peak peak-approach countdown no longer appends the default-rate hint「平时 1×」, and the Settings peak row shows just the configured multiplier (e.g. `2×`). A multiplier is only annotated when it deviates from the normal 1× rate: peak hours show their multiplier (configurable, may become 5×), and if an off-peak discount (free / 0.5×) is ever introduced it will be labeled there — the default rate itself stays unlabeled.

## 简体中文

非高峰的「距高峰期」倒计时不再附带「平时 1×」默认价标注，设置页倍率只显示配置值（如 `2×`）。倍率只在偏离平时 1× 时才标注：高峰期显示当前倍率（未来可配置 5×），未来若引入闲时折扣（免费 / 0.5×）才在闲时行标注——默认价本身不额外提示。
