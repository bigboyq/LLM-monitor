# LLM Monitor 2.3.6

## English

The Prompt-speed range chart and its shared-scale legend are removed from expanded client sections. Each model row is now a single metrics line (name · Pmt · Token · 价值 · 命中 · 思考 · 速度), saving two rows per model; the `速度` text (P50, tok/s) in model rows and client summaries is unchanged.

## 简体中文

展开客户端段后，模型行不再绘制 Prompt 速度范围图与「共享刻度」图例。每个模型行收为单行指标（模型名 · Pmt · Token · 价值 · 命中 · 思考 · 速度），腾出每行两行高度；模型行与客户端摘要的「速度」文本（P50，tok/s）保持不变。
