# LLM Monitor 2.3.7

## English

Usage client sections now render as an indented tree instead of stacked cards. Level one is the harness row (▸/▾ disclosure triangle, client icon, name, scan time on the right; the right-click refresh action is unchanged); the today summary line stays indented beneath the name. When expanded, model rows form level two with ├─ tick marks and a vertical guide line. A model used by several harnesses still expands under each harness. The rounded card background is gone.

## 简体中文

用量客户端段改为缩进树形，不再叠放方块卡片。第一级是 harness 行（▸/▾ 展开三角 + 客户端图标 + 名称 + 右侧扫描时间；右键刷新入口不变），名称下方缩进保留今日摘要行；展开后第二级为模型行，带 ├─ 短刻线与左侧竖引导线。同一模型被多个 harness 使用时，仍在各自 harness 下展开。原圆角卡片底色移除。
