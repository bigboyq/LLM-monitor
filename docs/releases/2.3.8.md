# LLM Monitor 2.3.8

## English

The harness summary now lives on the harness row itself in the usage tree: collapsed sections are a single line (name · Pmt · Token · 价值 · 命中 · 思考 · 速度 · scan time) and expanded sections add one row per model. Both levels share fixed-width columns so fields align vertically; the panel width (460pt) fits the full field union, so per the alignment rule the union is used. The scan time occupies a fixed trailing slot that model rows leave empty to keep columns aligned.

## 简体中文

用量树形中 harness 汇总合并到 harness 同一行：折叠即一行（名称 · Pmt · Token · 价值 · 命中 · 思考 · 速度 · 扫描时间），展开后每个模型一行。两级行共用定宽列，字段纵向对齐；面板宽度（460pt）实测装得下全部字段的并集，按「够并集取并集」的裁定执行。扫描时间占固定右侧尾槽，模型行留空同宽以保证列对齐。
