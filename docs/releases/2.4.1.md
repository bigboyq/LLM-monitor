## English

### Clearer expired-token guidance

- The Antigravity token-expired message now reads "token 已过期：在 Antigravity 中发起一次对话即可刷新凭据". Antigravity renews its token lazily — the Keychain entry updates only when the IDE actually makes a model call, so an open-but-idle Antigravity does not refresh the credential. Send any message in Antigravity and the card recovers automatically on the next refresh cycle (≤5 minutes). The export script message matches.

## 简体中文

### 更明确的 token 过期指引

- Antigravity token 过期提示改为「token 已过期：在 Antigravity 中发起一次对话即可刷新凭据」。Antigravity 的 token 是懒刷新——只有 IDE 实际发起模型调用时才续期写回钥匙串，「打开但闲置」不会刷新。在 Antigravity 里发一条消息，下一个刷新周期（≤5 分钟）额度卡自动恢复。`export-antigravity-quota.sh` 的过期提示同步。
