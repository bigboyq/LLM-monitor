# LLM Monitor 2.4.3

[English](#english) · [简体中文](#简体中文)

## English

### Quota source path shown in Settings

- The Antigravity settings pane now shows a read-only "额度来源" (quota source) row right below the "允许监控刷新 Token" toggle: it reports which path the current quota data came from — remote Cloud Code (Keychain credentials) or the local `language_server` fallback (shown when the Keychain credential is expired or unavailable). A neutral "—" placeholder is displayed until the first successful refresh in this session; the pane's "立即刷新" button reports the actual path of that refresh immediately.

## 简体中文

### 设置页展示额度来源路径

- Antigravity 设置 pane 在「允许监控刷新 Token」开关下方新增只读「额度来源」行：显示当前额度数据实际走的路径——远端 Cloud Code（钥匙串凭据）或本地 language_server 回退（钥匙串凭据已过期或不可用时）。本会话尚无成功刷新时显示中性占位「—」；设置页「立即刷新」完成后立即反映当次实际路径。
