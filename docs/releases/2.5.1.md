# LLM Monitor 2.5.1

[English](#english) · [简体中文](#简体中文)

## English

### Right-click menu rework + "Open Settings Directory" in Settings

- **Menu-bar right-click menu is now 刷新 / 设置 / 退出**: the 「设置」 entry opens the Settings window directly via the hosted `SettingsLink`; the old 「打开配置文件」 item is gone.
- **New 「打开设置目录」 button** in Settings → General: a new 「配置文件」 section opens the configuration directory `~/Library/Application Support/LLM-monitor/` in Finder with `config.json` selected, for hand editing and troubleshooting. Saving the file still hot-reloads automatically.

### Removed

- **「打开配置文件」 entry**: the old "open config.json with the system default app" capability is removed entirely (right-click menu item and the menu empty-state button), with no replacement entry. Use 「打开设置目录」 in General to locate the file in Finder instead.

## 简体中文

### 右键菜单重构 + 设置页「打开设置目录」

- **菜单栏右键菜单改为「刷新 / 设置 / 退出」**：「设置」经托管的 `SettingsLink` 直接打开设置窗口；原「打开配置文件」条目删除。
- **常规 pane 新增「打开设置目录」按钮**：新增「配置文件」节，用 Finder 打开配置目录 `~/Library/Application Support/LLM-monitor/` 并选中 `config.json`，方便手工编辑与排障；编辑保存后 App 仍自动热重载。

### Removed

- **「打开配置文件」入口**：旧「用系统默认应用打开 config.json」的能力整体删除（右键菜单条目与菜单空态按钮一并移除），不做替代入口；需要手工编辑配置时改用常规 pane 的「打开设置目录」在 Finder 中定位文件。
