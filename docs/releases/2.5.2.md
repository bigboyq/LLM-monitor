# LLM Monitor 2.5.2

[English](#english) · [简体中文](#简体中文)

## English

### Fixed

- The right-click "设置" menu entry was invisible since its introduction: a view-hosted `SettingsLink` does not render inside an `NSMenu` popped up from the menu-bar icon. The entry is now a plain `NSMenuItem` that opens the Settings window through the SwiftUI `OpenSettingsAction` injected via `SettingsOpenerBridge` (fallback: the `showSettingsWindow:` selector). Menu structure is unchanged: 刷新 / 设置 / 退出.

## 简体中文

### 修复

- 右键菜单「设置」条目自引入起从未显示：view 宿主的 `SettingsLink` 在菜单栏图标 popUp 出来的 NSMenu 里不渲染。现改为普通 `NSMenuItem`，经 `SettingsOpenerBridge` 注入的 SwiftUI `OpenSettingsAction`（`\.openSettings`）打开设置窗口（缺省回退 `showSettingsWindow:` 选择器）。菜单结构不变：刷新 / 设置 / 退出。
