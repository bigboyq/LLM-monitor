# LLM Monitor 2.5.3

[English](#english) · [简体中文](#简体中文)

## English

### Added

- **TTFT (time-to-first-token) across local usage surfaces.** `LocalTokenUsageSample` gains `ttftSeconds` (seconds; optional, old caches decode as nil) with aggregation in `LocalUsageSummaryBuilder` (call-level P50 via `callTTFTStatistics`, window mean via `windowTTFTMeanSeconds`, Σ/Σ merge intermediates for multi-pool combining). Three UI placements:
  - Harness list (menu): a **TTFT** column between Speed and Value (`Turns · Token · Hit · Think · Speed · TTFT · Value · Update`), call-level P50 over today's samples.
  - Plan details (quota window, 用量 mode): a **TTFT** column between Reason and 速度 (`horizontalSpacing` 8 → 6; TTFT and the usage-mode 速度 column are 30pt each to keep the 420pt budget; the 分析 mode keeps 7 columns), window mean.
  - Seven-day usage history: a **TTFT** metric between 命中 and 速度, daily call-level P50 in seconds.
- **Per-harness TTFT collection** (cache index versions bumped to force one-shot rebuild): ZCode native `model_usage.time_to_first_token_ms` (NULL-aware, v12); Codex `task_complete` payload TTFT backfilled onto the turn's first call (v2); Antigravity `gen_metadata` blob `f1.f11` (v10); agy same field joined by `steps.idx` (100% hit on a 91-database local scan, v4); DSH derived from the first `assistant/chunk.time − step/start.time` with per-step decode throttling (non-v4 files, v6); MiniMax Code writes an explicit `0` (no upstream data, user decision, v17); OpenCode has no field and stays `—`.

## 简体中文

### 新增

- **TTFT（首字延迟）接入三处本地用量展示。** `LocalTokenUsageSample` 新增 `ttftSeconds`（秒；可选字段，旧缓存解码得 nil），聚合唯一实现在 `LocalUsageSummaryBuilder`（调用级 P50 `callTTFTStatistics`、窗口均值 `windowTTFTMeanSeconds`、多池 Σ/Σ 合并中间量）。三处 UI：
  - Harness 列表（菜单）：Speed 与 Value 之间新增 **TTFT** 列（`Turns · Token · Hit · Think · Speed · TTFT · Value · Update`），今日样本的调用级 P50。
  - Plan 详情（额度窗口「用量」态）：Reason 与速度之间新增 **TTFT** 列（`horizontalSpacing` 8 → 6，TTFT 与用量态速度列各 30pt 保住 420pt 预算；「分析」态保持 7 列），窗口均值口径。
  - 7 天用量历史：命中与速度之间新增 **TTFT** 指标（每日调用级 P50，单位秒）。
- **逐 harness TTFT 采集**（各缓存版本递增、一次性失效重建）：ZCode 原生 `model_usage.time_to_first_token_ms`（NULL-aware，v12）；Codex `task_complete` payload 的 TTFT 回填到该 turn 首条样本（v2）；Antigravity `gen_metadata` blob `f1.f11`（v10）；agy 同字段按 `steps.idx` 连接（本机 91 库实测 100% 命中，v4）；DSH 取首个 `assistant/chunk.time − step/start.time`（非 v4 文件，逐 step 首 chunk 节流解码，v6）；MiniMax Code 无上游数据、显式写 0（用户裁定，v17）；OpenCode 无字段、显示 `—`。
