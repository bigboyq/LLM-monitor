# LLM Monitor 2.5.4

[English](#english) · [简体中文](#简体中文)

## English

### Fixed

- **MiniMax Code TTFT is now derived, not hardcoded zero.** Re-inspection found the original research had missed the `decode_duration_ms` key inside `data_json.$.usage`. The duration gate query now also extracts it and the same `(session, turn)` FIFO pairing produces `ttftSeconds = (request_duration_ms − decode_duration_ms) / 1000` (missing decode or negative delta → nil; measured coverage 94.5% with 99.1% non-negative deltas across 14,665 ledger rows). The char-split rebuild path preserves `ttftSeconds` the same way it preserves `durationSeconds`; cache index v17 → v18.
- **DSH TTFT now covers v3 / v4 ledgers.** The original dissection of v4 only inspected the failed-turn `assistant/attempt.data.stream` and missed that successful calls embed the chunk stream in `assistant/message.data.stream[]` with per-chunk timestamps. The scanner now derives `ttftSeconds = stream[0].time − step/start.time` for v3 / v4 messages (v3 measured 1094/1094 and 15/15 calls diffable, P50 2.35s / 2.07s; v4 70/70 and 1/1, P50 827ms), while v1 keeps its separate `assistant/chunk` line path. Cache index v6 → v7.

With this release all three DSH ledger generations and all seven clients except OpenCode provide TTFT; UI columns added in 2.5.3 light up without code changes.

## 简体中文

### 修复

- **MiniMax Code 的 TTFT 改为真实推导，移除硬编码 0。** 复核发现初版调研漏了 `data_json.$.usage` 里的 `decode_duration_ms` 键。时长守门查询同一查询补取该键，沿用同一 `(session, turn)` FIFO 配对，`ttftSeconds = (request_duration_ms − decode_duration_ms) / 1000`（decode 缺失或差值 < 0 → nil；全库 14,665 行实测覆盖 94.5%、差值非负 99.1%）。字符分摊重建路径与 `durationSeconds` 同模式保留 `ttftSeconds`；缓存 v17 → v18。
- **DSH 的 TTFT 覆盖 v3 / v4 账本。** 初版对 v4 只解剖了失败 turn 的 `assistant/attempt.data.stream`，漏看了成功调用把 chunk 流打包在 `assistant/message.data.stream[]`（逐条带 time）。scanner 现按 `stream[0].time − step/start.time` 推导 v3 / v4 的 TTFT（实测 v3 1094/1094、15/15 可差分，P50 2.35s / 2.07s；v4 70/70、1/1，P50 827ms）；v1 仍走独立 `assistant/chunk` 行路径。缓存 v6 → v7。

至此 DSH 三代账本全部可推导，七个客户端中除 OpenCode（账本无字段）外均提供 TTFT；2.5.3 新增的三处 UI 列无需改动即自动点亮。
