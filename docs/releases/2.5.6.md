# LLM Monitor 2.5.6

[English](#english) · [简体中文](#简体中文)

## English

### Changed

- **Harness list Speed tooltip now shows the actual distribution.** Hovering a Speed cell (section header or model row) displays `Min: x · P50: x · P95: x · Max: x tok/s` from that row's prompt speed statistics instead of a static wording; a coverage suffix (`（v/m Prompt 有有效时长）`) appears when some prompts lack valid durations, and rows without any valid sample fall back to the original wording. `PromptSpeedStatistics` gains `p95` (nearest-rank: the ⌈0.95·n⌉-th observed value).

### Fixed

- Removed the outdated「MiniMax Code 无数据恒为 0」clause from the TTFT column tooltips (harness list and quota window) — MiniMax Code has derived real TTFT since 2.5.4.

## 简体中文

### 变更

- **Harness 列表 Speed 列 tooltip 改为实际分布。** 悬停 Speed 格（段头或模型行）显示该行 Prompt 速度统计的 `Min: x · P50: x · P95: x · Max: x tok/s`；有 Prompt 缺有效时长时尾注 `（v/m Prompt 有有效时长）`，无有效样本时回退原口径文案。`PromptSpeedStatistics` 新增 `p95`（就近秩法：第 ⌈0.95·n⌉ 个观测值）。

### 修复

- 删除 TTFT 列 tooltip 里过时的「MiniMax Code 无数据恒为 0」（harness 列表与额度窗口两处）——2.5.4 起 MiniMax Code 已是真实推导值。
