# LLM Monitor 2.6.5

## English

### Changed

- Select a status-bar quota by provider and source: the main plan, an individual ChatGPT API credit key, or a ZCode activity-plan entitlement. Existing provider pins migrate to the main plan.
- Single-window quotas use a circular gauge with a centered percentage and one sleep-health indicator embedded in the 12 o'clock notch. The lamp and arc share one circumference, with a small gap on each side of the lamp. Dual-window plans retain the dual-arc dashboard; single gauges have no bottom quota-health dots.
- Percentage typography adapts to the displayed digit count: 0–9 is largest, 10–99 medium, and 100 smallest, with a reduced percent sign and consistent centering.
- Explicit selections stay selected when data is unavailable. Unknown readings show a gray dash instead of silently falling back to another provider. Global mode retains the existing nonzero-minimum plan relay.

## 简体中文

### 调整

- 状态栏按 Provider 与额度来源选择：主套餐、单个 ChatGPT API 赠金 Key、单份 ZCode 活动权益；旧小眼睛选择自动迁移到对应主套餐。
- 单窗口采用圆形额度环与居中百分比，休眠灯嵌在同一圆周的 12 点缺口内，两侧各留少量间隙；移除底部额度健康灯，双窗口保留双弧仪表盘。
- 百分比按显示位数自适应字号：0～9 最大、10～99 次之、100 最小，各档保持居中并缩小百分号。
- 选中来源暂无读数时保留选择并显示灰色横线，不自动跳到其他 Provider。未选 Provider 时继续采用全局非零最小有效额度。
