# LLM Monitor 2.7.0

## English

### Changed

- Consolidates the quota-display redesign: classify 5-hour and weekly quotas by their actual windows, render single-window gauges, and select a provider, main plan, API credit key, or activity entitlement. Missing data remains unknown.
- Single- and dual-window status-bar gauges share centered digits without a percent sign; 100% displays as `00`. The dual-window center shows effective 5-hour quota. The sleep lamp sits in the top notch with 0.75 lamp diameters of clearance on each side.
- The edge dock supports single quota rings and a DeepSeek account-status ring, with the same stroke width as the dual-ring outer circle. Dragging preserves the grab position and saves the final snapped location.

### Fixed

- Corrects Swift 6 concurrency declarations in LAN and related modules while preserving cache synchronization and existing behavior.

## 简体中文

### 调整

- 汇总本轮额度展示重设计：按真实窗口归类 5h/周额度，支持单窗口进度圈，以及 Provider、主套餐、API Key 和活动权益来源选择；缺失数据保留未知状态。
- 状态栏单、双额度共用居中数字，省略百分号，100% 显示为「00」；双额度中心显示有效 5h 额度。休眠灯嵌入顶部缺口，两侧各保留 0.75 个灯直径的净空。
- 边缘悬浮窗支持单额度圈与 DeepSeek 账户状态圈，统一单圈和双圈外环线宽；拖动保持抓取位置并保存最终吸附落点。

### 修复

- 修复 LAN 等模块的 Swift 6 并发声明问题，保持缓存同步与现有行为。
