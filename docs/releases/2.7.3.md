# LLM Monitor 2.7.3

## English

### Changed

- Switch menu usage speed (`CallSpeedStatistics`) and 7-day speed history from all-or-nothing turn grouping to individual effective call statistics (`Min / P50 / P95 / Max` and `latest`), skipping only invalid/missing-duration calls without disqualifying sibling streaming calls in the same turn while keeping `Turns` keyed by distinct `promptID`.
- Add status-bar pin eyes (`StatusBarQuotaSource.planModel(modelName:)`) next to every quota progress bar: multi-model plans keep the main-plan aggregate eye in the heading and expose per-model bar eyes (allowing explicit single-model monitoring for Antigravity `Gemini 4 Argon` / `Claude and GPT models`, MiniMax `video`, etc. while preserving `aggregateQuotaModels` defaults elsewhere), and single-model plans remove the duplicate heading eye in favor of the progress bar eye.

## 简体中文

### 变更

- 菜单用量 Speed 与 7 天速度历史从整轮全票口径调整为单次有效调用统计（保持 Min / P50 / P95 / Max 与最新值口径），仅剔除缺失或无效解码时长的单次调用本身，不再连坐同轮内正常流式调用；Turns 列仍按去重 `promptID` 计数。
- 所有额度进度条旁均增加状态栏来源小眼睛（`StatusBarQuotaSource.planModel(modelName:)`）：多模型套餐保留主套餐大标题聚合小眼睛，并在每条模型进度条旁提供独立直选（支持在保留默认 `aggregateQuotaModels` 聚合规则的同时单独盯住 `Gemini 4 Argon`、`Claude and GPT models`、MiniMax `video` 等）；单模型套餐取消主套餐大标题处重复小眼睛，直接由唯一进度条承载主套餐选择。
