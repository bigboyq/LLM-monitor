# LLM Monitor 2.7.4

## English

### Fixed

- Eliminate all Swift 6 concurrency and compiler warnings across `Sources/` (both debug and release builds in Swift 6 language mode and Swift 5 builds): annotate challenge delegate forwarding callbacks as `@Sendable`, replace deprecated UTF-8 C-string initializers in `LANAddressResolver`, declare `FleetCardContext` `Sendable` with `@MainActor @Sendable` `onScopeChange`, convert `QuotaUpdateNotifier` marketing notification delivery inside async `Task` to `try await`, mark pure view static helpers/constants `nonisolated`, wrap UI closure conversions cleanly, and tighten `MinimaxDBReader`'s local resolver binding to `let`. Also update `HTTPClientTests` challenge-callback assertions to use lock-synchronized `OSAllocatedUnfairLock` state.
- Make `EdgeDockController.checkDynamicMenuBar(at:windowEntries:)` deterministically injectable for dynamic menu bar tests and isolate `EdgeDockFullscreenTests` (`testDynamicMenuBarTouchingTopEdgeRequiresMouseToBeOnTargetScreen` and `testDynamicMenuBarRecoversWhenMouseLeavesTopEdgeOrScreen`) from live desktop windows and shared controller drag/fullscreen state so assertions always execute cleanly.

## 简体中文

### 修复

- 清理 `Sources/` 在 Swift 5 与 Swift 6（Debug / Release）构建下的全部并发与编译器警告：为 `CappedDownloadDelegate` 认证转发回调显式补充 `@Sendable`、`LANAddressResolver` 改用 `String(validatingCString:)` 与 null 截断后 UTF-8 解码、`FleetCardContext` 声明 `Sendable`（`onScopeChange` 标为 `@MainActor @Sendable`）、`QuotaUpdateNotifier` 活动通知改用异步 `try await center.add`、纯视图静态常量与方法标注 `nonisolated`、规范视图层回调传递，并将 `MinimaxDBReader` 未重绑的 `resolver` 改为 `let`；同步更新 `HTTPClientTests` 回调测试改用 `OSAllocatedUnfairLock` 同步状态。
- 为 `EdgeDockController.checkDynamicMenuBar(at:windowEntries:)` 增加默认为 `nil` 的可注入窗口列表参数，并在 `EdgeDockFullscreenTests` 中隔离 `isDragging` / `isFormMorphInFlight` / `isFullscreenSpace` 状态、传入空窗口快照，消除受宿主机真实全屏窗口干扰导致动态菜单栏复位测试跳过或偶然失败的问题。
