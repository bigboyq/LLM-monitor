# LLM Monitor 2.7.5

## English

### Changed

- Unify status-bar pin eyes across single-model and multi-model providers: remove the duplicate `.plan` pin button next to the `mainPlanTitle` heading inside `QuotaSummary` for all providers (including Antigravity and MiniMax alongside ChatGPT and GLM), keeping the top-right `StatusBarQuotaSelector` as the single Provider-level `.plan` aggregate toggle (with right-click context menu for all sources) and keeping per-bar / API Key / activity-plan `StatusBarQuotaSourcePinButton` controls for direct source pinning.
- Allow clicking an already-selected solid `StatusBarQuotaSourcePinButton` (`.plan`, `.planModel`, `.apiCredit`, or `.activityPlan`) to clear `statusBarQuotaSelection` back to `nil` (global relay) across the menu, edge dock popover, and provider detail window via `AppState.toggleStatusBarQuotaSelection(providerID:source:)`, with updated tooltip/accessibility labels.

## 简体中文

### 变更

- 统一菜单与卡片的「小眼睛」固定规则：移除 `QuotaSummary` 主套餐大标题（`mainPlanTitle`）旁对 Antigravity / MiniMax 等多模型套餐的重复 `.plan` 小眼睛，与 ChatGPT / GLM 保持一致仅保留名称文本；卡片 / 菜单右上角 `StatusBarQuotaSelector` 统一承担 Provider 级 `.plan` 聚合开关与右键来源菜单，各模型进度条、ChatGPT API Key 与 GLM ZCode 活动套餐标题旁的 `StatusBarQuotaSourcePinButton` 承担独立来源固定。
- 支持再次点击已选中的实心来源小眼睛（`StatusBarQuotaSourcePinButton`）取消锁定并恢复全 Provider 接力聚合（`statusBarQuotaSelection = nil`）；菜单、边缘窗与独立详情窗统一通过 `AppState.toggleStatusBarQuotaSelection(providerID:source:)` 执行切换，并同步更新按钮提示与辅助功能文案。
