# LLM Monitor 2.7.8

## English

### Fixed

- Fix ChatGPT API credits (API赠金) boundary-day carry edge cases: prevent UTC `00:00` cycle anchors (including the default local `08:00` in UTC+8) from treating Day-1 UTC buckets as prior-cycle spill-over (`bucket.startTime < cycleStart < bucket.endTime`); cache `$0` omitted boundary buckets inside the 1h snapshot window; always stamp `usedAmountAdjustFixedAt` across billing cycles even when the new cycle's carry matches the previous cycle's `usedAmountAdjust`; keep concurrent sibling provider refreshes and local-usage scans alive instead of deferring when carry writebacks save to config; persist carry writebacks for legacy scalar `adminApiKey` fallback configs; reset `usedAmountAdjustFixedAt` when `billingDay` or `billingTime` changes in Settings without manual `usedAmountAdjust` edits; normalize `-0.0` in Settings draft formatting and format negative boundary carry in tooltips as `-$X.XX`.
- Fix GLM ZCode `loadCredentials(authPath:)` unnecessarily decrypting the unused `oauth:bigmodel:access_token` (eliminating redundant Keychain reads) and skip disk `credential-secret` reads on `enc:v2:os:` branches.
- Guard against negative or non-finite `ttftSeconds` in `LocalTokenUsageSample.hasValidDecodeDuration`, and preserve a pinned `.planModel` status bar selection when a multi-model provider temporarily shrinks to a single active model.

## 简体中文

### 修复

- 修复 ChatGPT API 赠金边界日扣除的多项边界问题：避免 UTC `00:00` 锚点（含东八区默认本地 `08:00`）将首日 UTC 桶误判为上一周期溢入（收紧为 `bucket.startTime < cycleStart < bucket.endTime`）；1 小时快照窗口内 OpenAI 省略的 `$0` 边界桶按 `0.0` 写入内存缓存；跨周期写回时即使新周期扣除值与上周期相同也正常打上 `usedAmountAdjustFixedAt` 时间戳；静默写回配置不再触发配置代际递增而打断并发兄弟 Provider 刷新或本地扫描；补齐旧版标量 `adminApiKey` 兼容路径的写回落盘；在设置页修改 `billingDay` / `billingTime` 且未手动修改边界扣除时重置 `usedAmountAdjustFixedAt`；修正设置草稿 `-0.0` 格式化及悬浮提示负数格式 `-$X.XX`。
- 修复 GLM ZCode `loadCredentials(authPath:)` 无谓解密未使用的 `oauth:bigmodel:access_token`（消除多余钥匙串读取），并避免 `enc:v2:os:` 分支读取磁盘 `credential-secret` 文件。
- 在 `LocalTokenUsageSample.hasValidDecodeDuration` 中拦截负数与非有限 `ttftSeconds`，并在多模型 Provider 临时缩水至单一活跃模型时保留已固定的 `.planModel` 状态栏选择。
