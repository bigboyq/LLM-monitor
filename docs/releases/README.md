## 已知的记录断档

- **1.3.0（2026-07-15）没有发布说明文件**。它的条目只存在于
  [CHANGELOG](../../CHANGELOG.md)——该文件是在 1.4.0 发布提交里才加入仓库的，早于它的
  tag（`1.0` / `1.1.0` / `1.2.0` / `1.2.1` / `1.2.2`）连 CHANGELOG 条目都没有。
- **1.12.0–1.19.0 没有条目**：CHANGELOG、本目录与 git tag 三处都没有。
- **1.4.0 的发布说明是「相对 1.3.0 的累计变化」**，跨版本细节请对照 CHANGELOG 阅读。

补写历史版本说明时以 CHANGELOG 已有条目为准，不要凭印象补内容。

## English

This directory archives one release-notes file per version, starting at **1.4.0**.
Earlier versions have no dedicated release notes — their user-facing changes live in
[CHANGELOG](../../CHANGELOG.md). Known gaps: 1.3.0 has no release-notes file, 1.12.0–1.19.0
have no entries anywhere, and versions older than 1.3.0 (tags `1.0` / `1.1.0` / `1.2.x`)
predate the CHANGELOG itself. This index deliberately does not invent content for them.
